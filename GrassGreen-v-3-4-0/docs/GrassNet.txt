!GrassNet! — Сетевая библиотека протоколов TCP/IP, HTTP/HTTPS и сокет-серверов

connect(ip, [port]) *С помощью этой команды можно подключиться к определённому IP адресу или домену*
send(url, [method], [body]) *С помощью этой команды можно отправлять http или https запросы на сервер или сайт*

agent
{
    browser "Chrome/124.0";
    device "Windows NT 10.0; Win64; x64"; *С помощью этой команды можно создать своего агента чтоб он мог заходить на сайты*
}

accept() *С помощью этой команды можно принимать входящие запросы на сервере*

create_serv()
{
    port: 443;
    IP: 127.0.0.1;          *С помощью этой команды можно создать свой сервер*
    password: 1234;
    certainIP: 127.0.0.1;
}

async *С помощью этой команды можно синхронизировать сетевые действия и потоки*
API("токен_или_ключ") *С помощью этой команды можно вставлять свои API-ключи в проект чтоб они работали в запросах*

// --- Дополнительные сетевые утилиты GrassNet ---
ping(host) *Измеряет реальную задержку (пинг в мс) до IP или домена*
resolve_ip(domain) *Преобразует доменное имя сайта в реальный IPv4 адрес (DNS)*
local_ip() *Возвращает локальный IPv4 адрес твоего компьютера в сети*
download(url, path) *Скачивает файл по прямой ссылке на диск*
net_status() *Возвращает HTTP-код последнего запроса (например 200 или 404)*
net_close() *Закрывает активные соединения и останавливает сервер*
