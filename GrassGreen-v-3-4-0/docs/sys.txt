!sys! — Системная библиотека взаимодействия с ОС Windows и мониторинга железа

clip_set(text) *Копирует текст в системный буфер обмена Windows (Ctrl+C)*
clip_get() *Считывает текст из системного буфера обмена Windows (Ctrl+V)*
screen_w() *Возвращает ширину основного монитора в пикселях*
screen_h() *Возвращает высоту основного монитора в пикселях*
pc_name() *Возвращает имя компьютера в сети*
user_name() *Возвращает имя текущего пользователя Windows*
cpu_cores() *Возвращает количество логических ядер процессора*
ram_total_mb() *Возвращает общий объём физической оперативной памяти (в МБ)*
ram_free_mb() *Возвращает объём свободной оперативной памяти (в МБ)*
get_env(name) *Считывает значение переменной среды Windows (например "PATH" или "TEMP")*
uptime_sec() *Возвращает время непрерывной работы системы (аптайм ОС) в секундах*
