[ 1. СИСТЕМНОЕ ЯДРО И СИНТАКСИС C++ ]
----------------------------------------------------------------------
int main() { ... }
  Главная входная точка выполнения программы. Завершается оператором return 0;.

take name(arg1, arg2) { ... }
  Объявление функции / процедуры без явного типа возврата (аналог void/auto).
  Выполняет блок инструкций над переданными аргументами.

return value;
  Прерывает выполнение текущей функции и передаёт вычисленный результат в стек.

for (int i = 0; i < N; i++) { ... }
  Классический итерируемый цикл со счётчиком, шагом и предусловием.

cout << val1 << val2 << endl;
  Потоковый вывод данных в стандартный вывод (STDOUT).
  endl выполняет перевод каретки и сброс системного буфера.

cin >> variable;
  Потоковое считывание данных из стандартного ввода (STDIN) в переменную.

text;
  Быстрый вывод пустой строки (пустого разделителя) в консоль.

/n;
  Инструкция принудительного переноса строки в консоли.


[ 2. ПОТОКИ И ФУНКЦИИ ВВОДА ДАННЫХ ]
----------------------------------------------------------------------
input(prompt, target_var)
  Отображает в консоли текст prompt и ожидает одиночный ввод (до первого пробела).
  Пример: input("Введите имя: ", user_name);

input.getline(prompt, target_var)
  Отображает текст prompt и считывает строку целиком вместе с пробелами (до Enter).
  Пример: input.getline("Адрес: ", full_addr);


[ 3. СТРОКОВЫЕ ОПЕРАЦИИ (STRING API) ]
----------------------------------------------------------------------
len(str) -> number
  Возвращает число символов в строке.

upper(str) -> string
  Транслирует все символы строки в верхний регистр (UPPERCASE).

lower(str) -> string
  Транслирует все символы строки в нижний регистр (lowercase).

substr(str, start, length) -> string
  Извлекает подстроку из текста начиная с позиции start фиксированной длины length.

replace(str, search, replacement) -> string
  Заменяет все подстроки search на replacement внутри переданного текста.

contains(str, substr) -> number
  Выполняет проверку вхождения подстроки. Возвращает 1 (найдено) или 0 (отсутствует).

trim(str) -> string
  Очищает строку от краевых пробелов, табуляций и переводов строк по обоим концам.

to_str(number) -> string
  Преобразует числовое значение в строковый тип данных.

to_num(str) -> number
  Парсит числовую строку в скалярное число с плавающей точкой.

typeof(var) -> string
  Интроспекция типа: возвращает строковый идентификатор ("string" или "number").


[ 4. СИСТЕМА, КОНСОЛЬ И ВЗАИМОДЕЙСТВИЕ С WINDOWS ]
----------------------------------------------------------------------
clear() / cls()
  Полная аппаратная очистка видеобуфера консоли Windows.

color("green" | "cyan" | "red" | "yellow" | "white" | "blue" | "gray")
  Устанавливает цветовой атрибут текста в консоли через Win32 SetConsoleTextAttribute.

time() -> number
  Возвращает текущий UNIX-таймстемп в секундах.

clock_ms() -> number
  Возвращает значение монотонного аппаратного счётчика времени в миллисекундах.

beep(frequency_hz, duration_ms)
  Генерирует звуковой сигнал через системный динамик заданной частоты и длительности.
  Пример: beep(750, 300);

msgbox(title, text)
  Вызывает модальное системное диалоговое окно Windows (MessageBoxA).
  Пример: msgbox("Статус", "Компиляция успешно завершена!");

system(command)
  Передаёт строковую команду напрямую командному интерпретатору ОС Windows (cmd.exe).
  Пример: system("tasklist");

exists(filepath) -> number
  Проверяет физическое наличие файла или директории по пути. Возвращает 1 или 0.

remove(filepath) -> number
  Удаляет указанный файл с диска. Возвращает 1 при успехе.


[ 5. ВСТРОЕННАЯ БАЗОВАЯ МАТЕМАТИКА ]
----------------------------------------------------------------------
pow(base, exp) -> number
  Возведение числа base в степень exp.

floor(val) -> number
  Округление числа с плавающей точкой до ближайшего меньшего целого.

ceil(val) -> number
  Округление числа с плавающей точкой до ближайшего большего целого.

clamp(val, min_val, max_val) -> number
  Ограничивает число val в пределах диапазона [min_val, max_val].
