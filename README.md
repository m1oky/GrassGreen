# GrassGreen (G&G) — Версия 4.2

GrassGreen — компилируемый язык программирования системного уровня с синтаксисом в стиле C++. Проект включает компилятор и виртуальную машину `grg` (бывший `grassc`), поддержку прямого выполнения байт-кода, генерацию автономных исполняемых файлов (`.exe` для Windows и исполняемых ELF-бинарников для Linux), нативный JIT-компилятор под архитектуру x86_64, а также современный векторный графический интерфейс VD+, встроенный аудио-движок, многопоточность, сетевой стек и инструменты прямого обращения к памяти (MMIO и Port I/O).

Официальный сайт: [grassgreen.info](https://grassgreen.info)  
Репозиторий: [github.com/m1oky/GrassGreen](https://github.com/m1oky/GrassGreen)

## Основные особенности версии 4.2

- **Векторный GUI-движок VD+ (Video Graphics Plus):**
  - Полный отказ от устаревших Win32-контролов в пользу чистого векторного компоузинга CSS-уровня с двойной буферизацией.
  - Адаптивная функция `auto_size_display()`: автоматическое определение разрешения монитора (Full HD, 2K, 4K) и масштабирования Windows DPI (125%, 150%, 200%) для устранения пикселизации и размытия.
  - Скругление углов всего окна приложения `border-radius-app(radius)` на уровне композитора DWM.
  - Настраиваемые стили шапок окна (`header`): `emerald` (фирменный изумрудный неоновый стиль), `native` (аккуратные 3 точки в стиле macOS), `glass` (акриловое размытие и прозрачность), `modern` (минималистичный стиль), `none` (полноэкранный режим без рамок с поддержкой плавного перетаскивания мышью).
  - Навигация и система страниц/вкладок: декларативное создание `tab = "Имя" { ... }` и мгновенное переключение через функцию `switch("Имя")`.
  - Синхронный виджет часов: `clock()` с посекундным автообновлением текущего времени.
  - Многослойность и Z-Index: всплытие активного окна на верхний слой при клике мышью.
  - Полноэкранный режим `fullscreen()`, фоновые светящиеся анимированные частицы `particles(count, color)` и аппаратный режим рендеринга `surface("freestanding")`.
- **Нативный аудио-движок `!audio!`:**
  - Прямой синтез частот и форм волны без внешних библиотек: чистый синус (`Sine`), меандр (`Square`), пила (`Sawtooth`), треугольник (`Triangle`) и белый шум (`Noise`).
  - Генерация тонов `audio_tone(freq, ms)` и системных сигналов `audio_beep(freq, ms)`.
  - Воспроизведение аудиофайлов формата WAV `audio_play(path)` и остановка `audio_stop()`.
  - Управление громкостью `audio_volume(vol)` и проверка статуса воспроизведения `audio_is_playing()`.
- **Полная кроссплатформенность (Linux + Windows):**
  - Универсальный скрипт установки [`install.sh`](install.sh) для всех дистрибутивов Linux (Arch Linux, Manjaro, Ubuntu, Debian, Fedora, openSUSE, Alpine, Void).
  - Сборка компилятора под Linux через [`build.sh`](build.sh) со стандартом C++20 и системными потоками `-pthread`.
  - Автономная генерация самораспаковывающихся ELF-бинарников под Linux (`grg -emit-exe program.grass -o program`).
  - Сохранение 100% нативной производительности под Windows через Win32 API, GDI+ и [`build.bat`](build.bat).
- **Прямая табличная диспетчеризация инструкций виртуальной машины (computed goto)** без цикла switch.
- **Представление всех базовых значений через 64-битный NaN-boxing** (ровно 8 байт на значение).
- **Аллокатор памяти Arena Allocator** со сдвигом указателя (bump-pointer) для быстрого выделения памяти под структуры и строки без фрагментации.
- **Нативный x86_64 JIT-компилятор** для горячих циклов с использованием регистров SSE2 и возвратом по стандарту вызовов Microsoft x64 ABI.
- **Многопоточность:** запуск системных потоков (`thread`), асинхронные вызовы (`async`), системные мьютексы и функции синхронизации.
- **Поддержка пользовательских структур (`struct`)** со строгим C-ABI выравниванием полей (1, 4, 8 байт) и динамических массивов (`array`).
- **Аппаратный доступ к памяти и портам (`!mmio!`):** прямое чтение и запись физических адресов (VGA-буфер, APIC), инструкции ввода-вывода x86 (`inb`/`outb`), барьеры памяти (`memory_barrier`, `read_barrier`, `write_barrier`) и ключевое слово `volatile`.
- **Фирменный потоковый ввод-вывод:** потоковый вывод `gout << ... << endl;` и ввод `gin >> var;` с прямым обращением к системным дескрипторам ядра ОС.
- **Официальное расширение VS Code v4.1.0** с полной TextMate подсветкой, сниппетами и IntelliSense для всех библиотек.

## Установка и сборка

### Вариант 1. Установка на Linux (Arch Linux, Ubuntu, Debian, Fedora и др.)

В корне репозитория находится универсальный установочный скрипт `install.sh`:
1. Сделайте скрипт исполняемым и запустите его:
   ```bash
   chmod +x install.sh
   ./install.sh
   ```
2. Скрипт автоматически:
   - Определит ваш дистрибутив Linux (Arch Linux / Manjaro: `pacman`, Ubuntu / Debian: `apt`, Fedora: `dnf`, openSUSE: `zypper`, Alpine: `apk`, Void: `xbps`).
   - Установит недостающие инструменты сборки (`base-devel`, `gcc`, `git`).
   - Скомпилирует компилятор `grassc` и виртуальную машину `grg` со стандартом C++20 и оптимизацией `-O3`.
   - Установит бинарники в `/usr/local/bin` (или `~/.local/bin`), настроит `$PATH` и зарегистрирует расширение для VS Code.
   - Проведет контрольный тестовый запуск.

Для быстрой локальной компиляции на Linux без установки в систему:
```bash
chmod +x build.sh
./build.sh
```

---

### Вариант 2. Установка на Windows через инсталлятор setup.exe

В корне репозитория и в папке `bin/` находится автономный графический установщик `setup.exe`:
1. Запустите `setup.exe`.
2. Выберите путь установки (по умолчанию `C:\GrassGreen`).
3. Нажмите "Установить". Установщик распакует компилятор `grg.exe`, лаунчеры `grg.cmd`, `grass.cmd`, `gg.cmd`, привяжет расширения файлов `.grass` и `.gdb` с официальными иконками, а также пропишет путь в переменную `PATH`.
4. Для автоматической тихой установки без диалоговых окон:
   ```cmd
   setup.exe /silent
   ```

После установки команда `grg` доступна из любой папки в терминале.

---

### Вариант 3. Сборка компилятора из исходников под Windows

Для сборки требуется компилятор GCC (MinGW-w64) с поддержкой стандарта C++20.
Запустите скрипт сборки в корне проекта:
```cmd
build.bat
```
Скрипт скомпилирует ядро и создаст исполняемые файлы `bin\grassc.exe` и `bin\grg.exe`, а также обновит глобальный каталог `C:\GrassGreen\bin`.

## Быстрый старт

Создайте файл `hello.grass`:

```cpp
!GrassGreen!

int main() {
    gout << "Привет из GrassGreen 4.1!" << endl;
    return 0;
}
```

Запуск скрипта в виртуальной машине:
```bash
grg hello.grass
```

Сборка в автономный исполняемый файл (`.exe` на Windows или исполняемый бинарник на Linux):
```bash
grg -O3 -emit-exe hello.grass -o hello.exe
```

## Команды компилятора grg

Компилятор вызывается командой `grg` (или `grassc`).

Основные флаги командной строки:

- `grg <файл.grass>` — компиляция и немедленный запуск скрипта в виртуальной машине.
- `-o <имя>` — указать имя выходного файла.
- `-c` — собрать только бинарный байт-код (`.grassc`) без сборки исполняемого `.exe`.
- `-emit-exe` — собрать байт-код вместе с загрузчиком в автономный исполняемый файл.
- `--jit` — принудительно включить нативный JIT-компилятор x86_64 для циклов.
- `-O0` — режим без оптимизаций (быстрая отладочная сборка).
- `-O1` — включить свертку констант и локальные оптимизации.
- `-O2` — включить слияние опкодов и удаление мертвого кода.
- `-O3` — максимальный уровень оптимизации (многопроходное слияние опкодов + автоматический JIT).
- `--dump-ast` — вывести структуру синтаксического дерева (AST) в терминал.
- `-S` — вывести дизассемблированный листинг байт-кода.
- `--time` — замерить время каждого этапа компиляции с точностью до миллисекунд.
- `--freestanding` — режим ядра без использования стандартной библиотеки C++.
- `-V`, `--version` — вывести версию компилятора.
- `-h`, `--help` — показать справку по всем флагам.
- `--ru` / `--en` — переключение языка сообщений компилятора.

## Примеры использования новых возможностей v4.1

### 1. Современный графический интерфейс VD+ (Video Graphics Plus)

```cpp
!GrassGreen!
!interface!

int main() {
    window {
        auto_size_display();        // Адаптивный расчет 2K/4K и Windows DPI (125%)
        border-radius-app(16);       // Скругление углов всего окна
        header("emerald");          // Стиль шапки: emerald, native, glass, modern, none
        title("GrassGreen VD+ Studio");
        size(720, 540);
        theme("dark");
        clock();                    // Виджет часов в правом верхнем углу

        tab = "Главная" {
            label "GrassGreen VD+ Video Graphics Engine" {
                window-ob(50, 40);
                size(620, 36);
                middle();
                text-color("#22c55e");
            }

            enter "Введите текст..." {
                window-ob(180, 110);
                size(360, 44);
                middle();
            }

            button "Открыть профиль ->" {
                window-ob(200, 180);
                size(320, 48);
                middle();
                switch("Профиль");   // Мгновенное переключение вкладки
            }
        }

        tab = "Профиль" {
            label "Панель управления профилем" {
                window-ob(50, 40);
                size(620, 36);
                middle();
            }

            button "<- Назад" {
                window-ob(200, 150);
                size(320, 48);
                middle();
                switch("Главная");
            }
        }
    }
    return 0;
}
```

### 2. Синтез звука и воспроизведение через `!audio!`

```cpp
!GrassGreen!
!audio!

int main() {
    // 1. Генерация чистого тона ноты Ля (440 Гц) на 1 секунду
    audio_tone(440, 1000);

    // 2. Синтез полифонической волны (0=синус, 1=меандр, 2=пила, 3=треугольник, 4=шум)
    audio_synth(523, 800, 2); // 523 Гц (Нота До), форма пила

    // 3. Воспроизведение WAV аудиофайла
    audio_play("sounds/notify.wav");

    // 4. Установка громкости (от 0 до 100%)
    audio_volume(85);

    return 0;
}
```

### 4. Многопоточность и синхронизация

```cpp
!GrassGreen!
!thread!

take compute_sum(take n) {
    take total = 0;
    for (take i = 1; i <= n; i++) {
        set total = total + i;
    }
    return total;
}

int main() {
    take t = thread(compute_sum, 1000000);
    take result = thread_join(t);
    gout << "Сумма в системном потоке: " << result << endl;
    return 0;
}
```

### 3. Встроенный ассемблер ядра (!asm!)

- Добавлена поддержка низкоуровневых ассемблерных вставок и инструкций процессора без внешних зависимостей (NASM/GAS).
- Прямая работа с системными регистрами, портами ввода-вывода и аппаратными прерываниями (`cli`, `sti`, `in`, `out`, `hlt`).
- Теперь код для запуска собственной операционной системы на голом железе пишется на 100% на одном языке GrassGreen.

```cpp
!GrassGreen!
!asm!

int main() {
    // 1. Управление прерываниями и системными регистрами процессора
    cli();                  // Запрет аппаратных прерываний
    write_cr3(0x1000);      // Установка каталога таблиц страниц PML4

    // 2. Встроенная ассемблерная вставка без внешнего NASM
    asm {
        cli
        xor eax, eax
        mov eax, cr0
        or eax, 1           // Включение защищенного режима PE
        mov cr0, eax
        sti
    }

    // 3. Прямой опрос и запись в порты ввода-вывода
    out(0x64, 0xFE);        // Команда сброса CPU через контроллер
    take key = in(0x60);    // Чтение скан-кода с клавиатуры PS/2
    gout << "Key scan code: " << key << endl;

    sti();                  // Включение прерываний
    hlt();                  // Остановка процессора до прерывания
    return 0;
}
```

## Поддержка в Visual Studio Code

В папках `.vscode/extension/` и `bin/` находится официальный пакет расширения `grassgreen-4.1.0.vsix`.

Расширение включает:
- TextMate подсветку синтаксиса всех 20 библиотек, управляющих конструкций, потокового вывода `gout`/`gin`, структур, стилей шапок, вкладок и ключевых слов.
- Официальные векторные иконки для файлов `.grass` (`logo.svg`) и файлов баз данных `.gdb` (`gdb_logo.svg`).
- 27 готовых сниппетов (IntelliSense) для быстрого создания окон VD+, вкладок, синтезаторов звука, потоков, мьютексов и шаблонов `main`.
- Горячие клавиши: `Ctrl+Shift+B` (сборка исполняемого файла) и `F5` (компиляция и запуск).

Установка расширения в редактор:
```bash
code --install-extension .vscode/extension/grassgreen-4.1.0.vsix
```
