## 💡 О проекте

Большинство пет-языков программирования представляют собой либо надстройки над Python с вызовом функции `eval()`, либо простые текстовые парсеры регулярных выражений. 

**GrassGreen** спроектирован по канонам системной разработки:
* Исходный файл `.grass` компилируется в плотный бинарный поток инструкций (байт-код), где каждая операция занимает от 1 байта.
* Виртуальная машина использует стековую модель вычислений (Stack-based Virtual Machine), работая напрямую со стеком значений и локальным пулом переменных.
* Упаковщик PE-Packer берет готовый байт-код и нативно линкует его внутрь автономного шаблона исполняемого файла Windows. Полученный `.exe` запускается на любой системе без предварительной установки Python, GCC, Visual Studio или библиотек распространяемого пакета Visual C++.

## 🛠 Ключевые технические решения

* **Нативный C++20:** Проект скомпилирован с флагами оптимизации `-std=c++20 -O3` и использует только стандартные заголовочные файлы и низкоуровневые сисколы WinAPI.
* **Автономные PE-бинарники:** Технология сигнатурной упаковки (`GRASSEXE`) позволяет собирать легковесные `.exe` файлы размером менее 1 МБ, включающие в себя и саму логику программы, и минимальный исполнительный рантайм.
* **Монолитная диспетчеризация модулей:** Встроенные библиотеки (`!FastMath!`, `!CoreMath!`, `!memory!`, `!random!`) залинкованы напрямую в диспетчер инструкций компилятора (`OP_CALL_BUILTIN`), что исключает накладные расходы на внешние вызовы через Foreign Function Interface (FFI).
* **Собственный расширенный стек памяти:** Модуль `!memory!` открывает возможность прямого аудита памяти операционной системы, замера использования ОЗУ текущим процессом и ручного выделения блоков байтов в системной куче.

## ⚡ Сравнение и бенчмарки

### Тестовый сценарий
Выполнение алгоритмического теста: прогон вложенных математических итераций до **30 000 циклов** без предварительной JIT-компиляции. Замеряются накладные расходы работы диспетчера виртуальной машины, работы со стеком и разрешения имен переменных.

| Среда / Компилятор | Подход к исполнению | Время выполнения | Зависимости |
| :--- | :--- | :--- | :--- |
| **C++20 (GCC 13.2 -O3)** | Прямой машинный код x86_64 | **< 1 мс** | Нет |
| **Python 3.12 (CPython)** | Байт-код с 30-летней кодовой базой C | **~90 мс** | Python Runtime (50+ MB) |
| **GrassGreen v3.0 (Stack VM)** | **Кастомная стек-машина (C++20 switch)** | **289 мс** | **Отсутствуют (Portable .exe)** |
| **Скриптовый строковый парсер** | Интерпретация через регулярные выражения | **> 3000 мс** | Python / Node.js |

> *Примечание:* GrassGreen работает на классической модели `switch-case` диспетчера опкодов. Разница во времени с CPython обусловлена отсутствием в текущей версии глобальных таблиц быстрых переходов (`computed gotos`) и кэширования опкодов, что является запланированным направлением оптимизации ядра.

## 💻 Синтаксис и примеры кода

### 1. Точка входа, структуры циклов и потоковый вывод

```cpp
!GrassGreen!

int main() {
    take total = 0;

    // Классический цикл for с инкрементом
    for (take i = 1; i <= 100; i++) {
        total = total + i;
    }

    cout << "Сумма чисел от 1 до 100: " << total << endl;
    
    if (total > 5000) {
        cout << "Статус: Вычисления успешны!" << endl;
    }

    return 0;
}
```

### 2. Прямой аудит системной памяти (`!memory!`)

```cpp
!GrassGreen!
!memory!

int main() {
    take free_ram = memory_free();
    take process_ram = memory_usit();

    cout << "Свободно ОЗУ в системе: " << free_ram << " MB" << endl;
    cout << "Использовано памяти процессом: " << process_ram << " KB" << endl;

    // Выделение сырого блока памяти в куче
    take block = memory_alloc(1024);
    cout << "Выделен дескриптор блока памяти: " << block << endl;
    memory_free_block(block);

    return 0;
}
```

### 3. Быстрая геометрия и тригонометрия (`!FastMath!`)

```cpp
!GrassGreen!
!FastMath!

int main() {
    take x1 = 10;
    take y1 = 20;
    take x2 = 50;
    take y2 = 80;

    // Вычисление расстояния между точками
    take dist = discor((x2 - x1) * (x2 - x1) + (y2 - y1) * (y2 - y1));
    cout << "Евклидово расстояние: " << dist << endl;

    // Линейная интерполяция
    take smooth_step = lerp(0, 100, 0.5);
    cout << "Интерполяция (50%): " << smooth_step << endl;

    return 0;
}
```

### 4. Квантовый регистр и криптографические операции (`!CoreMath!`)

```cpp
!GrassGreen!
!CoreMath!

int main() {
    // Инициализация квантового вентиля Адамара
    take qubit = h(0);
    
    // Получение непредсказуемого состояния кубита
    take collapsed = q_rand(qubit);
    cout << "Результат коллапса квантового регистра: " << collapsed << endl;

    return 0;
}
```

## 🏗 Архитектура компилятора и VM

Пайплайн трансляции исходного кода состоит из 4 последовательных этапов:

```text
[ Исходный код .grass ]
          │
          ▼
   [ Лексер и Токенизатор ]   -->  Разбиение на лексемы (TOK_IDENT, TOK_FOR, TOK_INT, etc.)
          │
          ▼
   [ Синтаксический парсер ]  -->  Построение таблицы инструкций, обработка скобочных областей {}
          │
          ▼
   [ Генератор опкодов ]      -->  Эмиссия инструкций стек-машины (OP_PUSH, OP_ADD, OP_JUMP)
          │
     ┌────┴─────────────────────────────┐
     ▼                                  ▼
[ Встроенная Стек-ВМ ]         [ PE-Packer ]
(Исполнение в консоли)         (Вшивание байт-кода в тело .exe бинарника)
```

## 🚀 Инструкция по сборке

### Требования
* Компилятор C++ с поддержкой стандарта C++20 (GCC / MinGW-w64 12.0+, Clang 15.0+ или MSVC 2022).
* Операционная система: Windows 10 / 11 (x64) или Linux (под Wine).

### Сборка компилятора через GCC / MinGW

```bash
# 1. Клонирование репозитория
git clone https://github.com/m1oky/GrassGreen.git
cd GrassGreen

# 2. Создание директории bin (если отсутствует)
mkdir bin

# 3. Полная компиляция ядра и библиотек с максимальной оптимизацией
g++ -std=c++20 -O3 src/grassc.cpp src/FastMath.cpp src/CoreMath.cpp src/GrassMemory.cpp src/GrassRandom.cpp -o bin/grassc.exe -lws2_32
```

### Использование компилятора

```bash
# Прямой запуск скрипта через встроенную виртуальную машину:
bin/grassc.exe examples/benchmark.grass

# Сборка скрипта в автономный .exe файл:
bin/grassc.exe examples/benchmark.grass -build

# Установка расширения и связей с редактором VS Code:
bin/grassc.exe --install
```

## 🎨 Интеграция с VS Code

Для языка разработана экосистема комфортной разработки под Visual Studio Code:
* Подсветка синтаксиса через `.tmLanguage` грамматику (типы данных, системные директивы `!модуль!`, операторы).
* Собственные сниппеты для мгновенного развертывания структуры `int main()`, условий и циклов.
* Сборка и запуск текущего открытого файла нажатием горячей комбинации клавиш **`Ctrl + Shift + B`**.
