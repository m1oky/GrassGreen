# Библиотека !sys! — Взаимодействие с системой и мониторинг железа

- `clip_set(text)` — Копирование переданного текста в системный буфер обмена Windows (Ctrl+C).
- `clip_get()` — Чтение текстового содержимого из буфера обмена Windows (Ctrl+V).
- `screen_w()` — Получение ширины экрана основного монитора в пикселях.
- `screen_h()` — Получение высоты экрана основного монитора в пикселях.
- `pc_name()` — Получение сетевого имени текущего компьютера.
- `user_name()` — Получение имени активной учетной записи пользователя Windows.
- `cpu_cores()` — Определение количества логических ядер процессора.
- `ram_total_mb()` — Общий объем физической оперативной памяти компьютера (в МБ).
- `ram_free_mb()` — Объем доступной свободной оперативной памяти (в МБ).
- `get_env(name)` — Чтение значения системной переменной среды (например, "PATH", "TEMP", "USERPROFILE").
- `uptime_sec()` — Время непрерывной работы операционной системы Windows (аптайм) в секундах.
