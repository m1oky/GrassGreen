# Библиотека !fsys! — Файловая система и директории

- `fs_mkdir(path)` — Создает новую директорию (возвращает 1 при успехе или 0).
- `fs_is_dir(path)` — Проверяет, является ли путь папкой (возвращает 1 или 0).
- `fs_size(path)` — Возвращает размер файла в байтах.
- `fs_copy(src, dst)` — Копирует файл в указанный путь (возвращает 1 при успехе или 0).
- `fs_list(path)` — Возвращает список всех файлов и папок внутри указанной директории.
- `fs_read(path)` — Читает всё текстовое содержимое файла в строку.
- `fs_write(path, text)` — Записывает строку в файл (перезаписывает существующий).
- `fs_append(path, text)` — Дописывает строку в конец указанного файла.
- `fs_delete(path)` — Удаляет указанный файл с диска.
- `fs_exists(path)` — Проверяет физическое наличие файла или папки по указанному пути.
