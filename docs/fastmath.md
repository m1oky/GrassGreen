# Библиотека !FastMath! — Быстрая вычислительная математика

- `discor(x)` — Квадратный корень из числа. Нужен, например, чтобы рассчитывать точное расстояние между точками на экране.
- `sin(x)` — Синус угла.
- `cos(x)` — Косинус угла.
- `abs(x)` — Модуль числа (превращает любой минус в плюс). Полезно, когда нужно узнать чистую разницу между координатами, не обращая внимания на направление.
- `round(x)` — Округление до ближайшего целого. Нужно, чтобы координаты элементов не становились дробными, иначе картинка начнёт двоиться и размываться.
- `min(a, b)` — Поиск минимального из двух чисел. Защищает интерфейс от вылетов (например, чтобы размер окна не ушёл в минус или не стал больше экрана).
- `max(a, b)` — Поиск максимального из двух чисел.
- `lerp(start, end, t)` — Линейная интерполяция. Самая главная функция для плавной анимации. Она берёт начальную точку, конечную точку и плавно двигает объект между ними в зависимости от времени t.
- `rand(min, max)` — Генератор случайных чисел в заданном диапазоне (рандом). Нужен для создания случайных эффектов, шумов или хаотичного мерцания.
