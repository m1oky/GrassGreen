# Библиотека !time! — Системные часы и профилирование времени

- `start_time()` — Запуск таймера замера времени выполнения блока инструкций.
- `stop_time()` — Остановка таймера замера и возврат затраченного времени в миллисекундах.
- `conclus_time()` — Получение отформатированной строки времени (например, "5.42 ms").
- `clock_ms()` / `now_ms()` — Текущее монотонное аппаратное время системы в миллисекундах.
- `time()` — Текущая временная метка (UNIX-таймстемп) в секундах.
- `get_date()` — Текущая дата строкой в формате "ГГГГ-ММ-ДД".
- `get_time_str()` — Текущее время строкой в формате "ЧЧ:ММ:СС".
