# Библиотека !audio! — Высокопроизводительный звуковой движок & Синтезатор GrassGreen 4.0

> **Статус:** Включено в базовый комплект библиотек GrassGreen v4.0.0  
> **Назначение:** Низкоуровневый процедурный синтез звуковых волн (PCM 44.1 кГц, 16 бит) без внешних файлов и высокоуровневое воспроизведение звуков всех форматов (.wav, .mp3, .ogg, .mid) с нулевыми зависимостями через нативный WinMM API.  
> **Философия:** 50/50 — максимальная скорость и контроль над формой звуковой волны в сочетании с лаконичным и читаемым высокоуровневым синтаксисом языка `.grass`.

---

## 1. Подключение библиотеки

Для использования звукового функционала добавьте директиву в начало вашего скрипта:

```grass
!GrassGreen!
!audio!

int main() {
    // Звуковой код здесь
    return 0;
}
```

## 2. Низкоуровневый синтез звука с нуля (Procedural Wave Synthesis)

Синтезирует звук программно в оперативной памяти с аппаратной дискретизацией 44100 Гц и проигрывает его через аудиодрайвер без треска и щелчков (с автоматическим 5 мс сглаживанием фронтов).

### `tone(freq_hz, duration_ms, volume = 80)`
Генерирует чистую синусоидальную звуковую гармонику заданной частоты и длительности:
- `freq_hz` — Частота звука в Герцах (например, `440.0` для Ноты Ля первой октавы, `880.0` для второй октавы).
- `duration_ms` — Длительность звучания в миллисекундах.
- `volume` *(опционально)* — Громкость от `0.0` до `100.0` (по умолчанию `80.0`).

```grass
// Нота Ля (440 Гц) длительностью 500 мс
tone(440, 500);

// Высокий чистый тон на 80% громкости
tone(880, 250, 80);
```

### `beep(freq_hz = 750, duration_ms = 300)`
Аппаратный короткий сигнал системного спикера / динамика:
- Идеально подходит для звуков нажатия кнопок, оповещений терминала и сигналов об ошибках.

```grass
beep(1000, 150); // Высокий короткий клик
```

### `synth_play(waveform, freq_hz, duration_ms, volume = 80)`
Универсальный генератор форм звуковых волн для создания игровых спецэффектов, музыки и звуковых сигналов:
- `waveform` — Форма волны:
  - `"sine"` — Мягкий гармонический тон (колокольчики, флейта, системные уведомления).
  - `"square"` (или `"8bit"`, `"retro"`) — Классический резкий 8-битный ретро-звук игровых консолей (NES/Dendy, GameBoy).
  - `"triangle"` (или `"tri"`) — Мягкий приглушенный бас и аналоговые синтезаторы.
  - `"sawtooth"` (или `"saw"`) — Насыщенный гармониками электронный тембр (EDM, сирены, лазеры).
- `freq_hz` — Базовая частота генерации.
- `duration_ms` — Длительность в миллисекундах.
- `volume` — Уровень громкости (0–100).

```grass
// 8-битный звук прыжка в игре
synth_play("square", 523, 120, 90);

// Электронный пилообразный бас
synth_play("sawtooth", 110, 400, 85);

// Мягкий треугольный колокольчик
synth_play("triangle", 659, 250, 70);
```

## 3. Воспроизведение аудиофайлов (Audio File Playback)

Движок поддерживает нативное воспроизведение треков и звуковых эффектов популярных форматов: `.mp3`, `.wav`, `.mid`, `.ogg`.

### `sound_play("path/to/sound.mp3", loop = 0)`
Запускает воспроизведение аудиофайла:
- `loop` — Флаг зацикливания: `1` для бесконечного фонового воспроизведения музыки, `0` для однократного воспроизведения звукового эффекта.
- Возвращает `1` при успешном старте или `0` при ошибке.

```grass
// Фоновый саундтрек в цикле
sound_play("music/theme.mp3", 1);

// Одиночный звуковой эффект
sound_play("sfx/click.wav");
```

### `sound_stop()`
Немедленно останавливает текущее воспроизведение и освобождает системный аудиодескриптор.

```grass
sound_stop();
```

### `sound_pause()`
Приостанавливает воспроизведение с сохранением текущей позиции трека.

```grass
sound_pause();
```

### `sound_resume()`
Возобновляет воспроизведение с места паузы.

```grass
sound_resume();
```

### `sound_volume(percent)`
Управляет системной громкостью воспроизводимого файла от `0` (тишина) до `100` (максимум).

```grass
sound_volume(50); // Установить 50% громкости
```

### `sound_is_playing()`
Возвращает `1`, если в данный момент играет файл, и `0`, если трек остановлен или закончился.

## 4. Комплексный пример: Музыкальная мелодия и синтезатор

```grass
!GrassGreen!
!audio!

int main() {
    gout << "Воспроизведение музыкального аккорда GrassGreen Synth..." << endl;

    // Мажорное трезвучие До-мажор: C5 (523 Гц), E5 (659 Гц), G5 (784 Гц)
    synth_play("sine", 523, 180, 80);
    synth_play("sine", 659, 180, 80);
    synth_play("sine", 784, 250, 90);

    // Ретро 8-битный проигрыш
    synth_play("square", 440, 100, 75);
    synth_play("square", 880, 150, 75);

    gout << "Синтез завершен успешно." << endl;
    return 0;
}
```
