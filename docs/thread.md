# Библиотека !thread! (!async!) — Многопоточность и синхронизация

- `thread(fn, ...args)` — Запуск функции в отдельном системном потоке операционной системы. Возвращает дескриптор потока.
- `async(fn, ...args)` — Создание асинхронной задачи с дескриптором потока.
- `async fn(...args);` — Оператор запуска функции в фоновом потоке без блокировки основного кода (fire-and-forget).
- `thread_join(t)` — Ожидание завершения работы потока и получение вычисленного им значения.
- `thread_detach(t)` — Отсоединение потока от родителя для продолжения автономной работы в фоне.
- `thread_id()` — Получение системного идентификатора (TID) текущего исполняемого потока.
- `thread_sleep(ms)` — Приостановка выполнения текущего потока на заданное количество миллисекунд.
- `mutex_create()` — Создание нового системного мьютекса для защиты общих данных от гонок.
- `mutex_lock(m)` — Захват мьютекса (блокировка входа в критическую секцию).
- `mutex_unlock(m)` — Освобождение мьютекса (разрешение доступа другим потокам).
- `mutex_destroy(m)` — Удаление мьютекса и освобождение дескриптора синхронизации.
