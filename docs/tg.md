# Библиотека !tg! — Интеграция с Telegram Bot API

- `telegram_init(token)` — Инициализация сессии бота с указанным токеном доступа Bot API.
- `send_message(chat_id, text)` — Отправка текстового сообщения в чат по его идентификатору.
- `get_updates()` — Получение новых входящих сообщений и событий от Telegram API.
- `send_photo(chat_id, photo_path)` — Отправка файла изображения в указанный чат.
- `send_document(chat_id, document_path)` — Отправка документа или произвольного файла в чат.
