# Библиотека !memory! — Управление оперативной памятью

- `memory_usit()` — Возвращает объем памяти, используемый процессом в данный момент (в МБ).
- `memory_separ()` — Перераспределение и дефрагментация блоков памяти.
- `memory_auto()` — Автоматический подбор оптимального размера пула памяти (Arena Allocator).
- `memory_clean()` — Принудительная мгновенная очистка арены памяти и неиспользуемых ресурсов.
- `memory_free()` — Информация о системе: объем установленной и доступной свободной оперативной памяти.
- `memory_alloc(bytes)` — Выделение непрерывного буфера байтов заданного размера для двоичных данных.
- `memory_free_block(id)` — Освобождение выделенного буфера памяти по его дескриптору.
- `memory_dump()` — Вывод отладочного слепка стека виртуальной машины и занятых переменных.
- `memory_limit(mb)` — Установка жесткого лимита потребления памяти процессом для защиты от утечек.
