# Спецификация движка создания языков !langgen! (docs/langgen.md)

Модуль `!langgen!` предназначен для высокоуровневого создания предметно-ориентированных языков (DSL), скриптовых сред и собственных компиляторов. Он полностью избавляет от необходимости вручную писать лексеры, функции `tokenize` и строковый парсинг, позволяя реализовать рабочий интерпретатор за 15–30 строк кода.

### Подключение модуля
```grass
!GrassGreen!
!langgen!
```

### Конфигурация грамматики и правил

- `lang_new(name)` — Создаёт экземпляр языка с именем `name` и возвращает его дескриптор.
- `lang_comment(lang, prefix)` — Устанавливает префикс однострочных комментариев (например, `"//"` или `"#"`). Все комментарии автоматически удаляются парсером без искажения номеров строк.
- `lang_rule(lang, rule_name, pattern)` — Регистрирует синтаксическое правило по шаблону `pattern`.

#### Поддерживаемые плейсхолдеры в шаблонах правил:
- `{id}` — Идентификатор (имя переменной, функции или команды).
- `{num}` — Числовая константа (целое или вещественное число).
- `{str}` — Строковый литерал в кавычках (кавычки автоматически снимаются при извлечении).
- `{expr}` — Выражение (математическое или логическое), продолжающееся до следующего разделителя правила (например, `;`).
- `{block}` — Вложенный блок кода в фигурных скобках `{ ... }` с автоматическим контролем баланса скобок.

### Парсинг и обход инструкций (AST)

- `lang_parse(lang, source_code)` — Выполняет разбор исходного кода по зарегистрированным правилам. При синтаксической ошибке выводит в консоль номер строки с понятным описанием ошибки. Возвращает дескриптор разобранной программы (списка инструкций).
- `lang_count(program)` — Возвращает общее количество успешно разобранных инструкций.
- `lang_cmd(program, index)` — Возвращает имя правила (`rule_name`), сработавшего на позиции `index`.
- `lang_arg(program, index, arg_index)` — Возвращает строковое значение аргумента плейсхолдера по индексу `arg_index` (начиная с 0).

### Вычислитель выражений и переменные среды

- `lang_eval(lang, expr_str)` — Встроенный быстрый вычислитель арифметических (`+`, `-`, `*`, `/`, `%`), побитовых (`&`, `|`, `^`, `<<`, `>>`) и логических (`==`, `!=`, `<`, `>`, `<=`, `>=`) выражений с поддержкой скобок и переменных среды языка.
- `lang_set_var(lang, name, val)` — Сохраняет переменную в среде выполнения языка `lang`.
- `lang_get_var(lang, name)` — Получает текущее значение переменной из среды выполнения.

### Пример создания собственного языка менее чем за 30 строк

```grass
!GrassGreen!
!langgen!

int main() {
    take lang = lang_new("SimpleDSL");
    lang_comment(lang, "//");
    lang_rule(lang, "var", "let {id} = {expr};");
    lang_rule(lang, "out", "print {expr};");
    lang_rule(lang, "loop", "repeat {num} times {block}");

    take code = "let a = 15;\nlet b = 5;\nprint a * b + 25;\nrepeat 3 times { print a; }";
    take prog = lang_parse(lang, code);
    take total = lang_count(prog);

    take i = 0;
    while (i < total) {
        take cmd = lang_cmd(prog, i);
        if (cmd == "var") {
            lang_set_var(lang, lang_arg(prog, i, 0), lang_eval(lang, lang_arg(prog, i, 1)));
        }
        if (cmd == "out") {
            gout << "[SimpleDSL]: " << lang_eval(lang, lang_arg(prog, i, 0)) << endl;
        }
        if (cmd == "loop") {
            take n = lang_eval(lang, lang_arg(prog, i, 0));
            take sub = lang_parse(lang, lang_arg(prog, i, 1));
            take k = 0;
            while (k < n) {
                take j = 0;
                while (j < lang_count(sub)) {
                    if (lang_cmd(sub, j) == "out") {
                        gout << "[SimpleDSL Loop]: " << lang_eval(lang, lang_arg(sub, j, 0)) << endl;
                    }
                    j = j + 1;
                }
                k = k + 1;
            }
        }
        i = i + 1;
    }
    return 0;
}
```
