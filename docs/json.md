# Библиотека !json! — Сериализация и парсинг JSON данных

- `json_get(json_str, path)` — Извлекает значение по ключу или пути (например, "status" или "user.name").
- `json_set(json_str, key, value)` — Добавляет или обновляет поле в JSON-строке.
- `json_valid(json_str)` — Проверяет валидность синтаксиса JSON (возвращает 1 или 0).
- `json_minify(json_str)` — Сжимает JSON-строку, удаляя лишние пробелы и переносы.
- `json_clear()` — Очищает внутренний буфер построителя JSON.
- `json_add(key, value)` — Добавляет строковое поле в текущий собираемый объект.
- `json_add_num(key, number)` — Добавляет числовое поле в собираемый объект.
- `json_build()` — Возвращает готовую скомпонованную JSON-строку.
- `json_parse(json_str)` — Полный парсинг JSON-строки в структуры рантайма.
- `json_stringify(val)` — Сериализация значения или структуры в строку JSON.
