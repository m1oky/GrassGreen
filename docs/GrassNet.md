# Библиотека !GrassNet! — Сетевые протоколы и сокет-серверы

- `connect(ip, [port])` — Подключение к определённому IP адресу или домену.
- `send(url, [method], [body])` — Отправка HTTP или HTTPS запросов на сервер или сайт.
- `agent { browser "..."; device "..."; }` — Настройка пользовательского агента браузера для выполнения сетевых запросов.
- `accept()` — Приём входящих сетевых подключений на сокет-сервере.
- `create_serv() { port: 443; IP: 127.0.0.1; password: 1234; certainIP: 127.0.0.1; }` — Конфигурация и запуск собственного TCP/IP сервера.
- `async` — Синхронизация сетевых действий и потоков обработки.
- `API("токен_или_ключ")` — Установка API-ключей и токенов авторизации для запросов.
- `ping(host)` — Измерение реальной задержки (пинг в мс) до IP-адреса или домена.
- `resolve_ip(domain)` — Преобразование доменного имени сайта в реальный IPv4 адрес (DNS).
- `local_ip()` — Получение локального IPv4 адреса текущего компьютера в сети.
- `download(url, path)` — Скачивание файла по прямой ссылке на локальный диск.
- `net_status()` — Возврат HTTP-кода ответа последнего запроса (например 200 или 404).
- `net_close()` — Закрытие активных сетевых соединений и остановка сокет-сервера.
