# Модуль !gfx3d! — 3D-графика и визуализация

Модуль `!gfx3d!` предоставляет высокопроизводительный движок трёхмерной графики для языка GrassGreen со встроенным программным растеризатором, Z-буферизацией, динамическим освещением и возможностью прямого вывода в линейный видеопамять (framebuffer) без операционной системы.

---

## Сцена, окно и камера

- `g3d_window(w, h, title)` — создание графического 3D-окна.
- `g3d_is_open()` — опрос цикла событий окна (возвращает 1, пока окно открыто).
- `g3d_clear(r, g, b)` — очистка буфера цвета и буфера глубины.
- `g3d_present()` — вывод отрендеренного кадра на экран.
- `g3d_dt()` — дельта времени (секунды) с прошлого кадра.
- `g3d_camera(pos_v3, target_v3, fov)` — настройка положения, направления и угла обзора камеры.
- `g3d_bind_framebuffer(addr, w, h, pitch)` — прямое связывание с видеобуфером для Bare-Metal.

---

## Меши и модели

- `g3d_cube(size)` — генерация кубического меша заданного размера.
- `g3d_sphere(radius, segments)` — генерация меша сферы.
- `g3d_plane(w, d)` — создание горизонтальной плоскости (пола).
- `g3d_load_obj(path)` — загрузка трёхмерных моделей в формате Wavefront `.obj`.
- `g3d_set_color(mesh, r, g, b)` — установка цвета меша.
- `g3d_transform(mesh, pos_v3, rot_v3, scale_v3)` — задание мировых координат, углов вращения и масштаба.
- `g3d_draw(mesh)` — отрисовка меша на сцене.

---

## Освещение и эффекты

- `g3d_dir_light(dir_v3, r, g, b, intensity)` — направленный источник света (солнце).
- `g3d_point_light(pos_v3, r, g, b, range)` — точечный источник света.
- `g3d_fog(r, g, b, density)` — атмосферный туман.
- `g3d_skybox(top_rgb, bottom_rgb)` — градиентное небо.
