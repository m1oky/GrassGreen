# Пакетный менеджер gpm (Grass Package Manager)

`gpm` — официальный кроссплатформенный пакетный менеджер и инструмент сборки проектов для языка программирования GrassGreen.

---

## Основные команды

### 1. Создание нового проекта
```bash
gpm init my_project
```
Разворачивает базовую файловую структуру проекта:
- `grass.cfg` — конфигурационный файл проекта с точкой входа и списком зависимостей.
- `src/main.grass` — шаблон точки входа программы.
- `libs/` — каталог для установленных зависимостей.
- `build/` — каталог для скомпилированных бинарных файлов.

### 2. Сборка и запуск
- `gpm build` — читает параметры из `grass.cfg` и компилирует проект в исполняемый файл.
- `gpm run` — собирает и запускает активный проект.

### 3. Создание новой библиотеки
```bash
gpm create my_lib
```
Создает структуру библиотеки для публикации:
- `package.json` — метаданные (имя, версия, автор, точка входа).
- `my_lib.grass` — исходный код модуля.
- `README.md` — описание библиотеки.

### 4. Генерация каталога реестра
```bash
gpm publish-index ./packages
```
Сканирует пакеты в указанной директории и формирует `index.json`, готовый для статической раздачи через GitHub Pages.

### 5. Установка пакетов
```bash
gpm install my_lib
```
Скачивает библиотеку в папку `libs/` и регистрирует её в `grass.cfg`.
