# Спецификация ядра !GrassGreen! (docs/main.md)

### Управляющие конструкции и базовый синтаксис
- `int main() { ... }` — Главная входная точка выполнения программы, завершается `return 0;`.
- `use utf - <id>;` — Установка активной кодировки терминала, кодовой страницы и раскладки клавиатуры (`use utf - 8;`, `use utf - 2;`, `use utf - 1251;`, `use utf - ru;`). Полная спецификация и таблицы нумерации: [docs/languages.md](languages.md).
- `take name(arg1, arg2) { ... }` — Объявление пользовательской функции с аргументами.
- `return value;` — Завершение выполнения функции с возвратом результата в стек.
- `if (условие) { ... } else { ... }` — Условное ветвление по результату логического выражения.
- `while (условие) { ... }` — Цикл с предусловием, повторяющийся пока условие истинно.
- `for (take i = 0; i < N; i++) { ... }` — Итерируемый цикл со счетчиком и шагом.
- `break;` — Немедленный выход из текущего цикла.
- `continue;` — Переход к следующей итерации цикла.
- `struct Name { field: type, ... }` — Объявление составного типа данных с C-ABI выравниванием.
- `take arr = []; arr.push(val); arr.pop();` — Инициализация динамического массива и методы работы с ним.
- `import "module.grass";` — Подключение внешнего модуля с семантикой `#pragma once`.

### Потоковый ввод-вывод (I/O Pipeline)
- `gout << val1 << val2 << endl;` — Потоковый вывод данных в консоль (через прямой Win32 WriteFile).
- `gin >> variable;` — Потоковое чтение данных из терминала в переменную (с аппаратной поддержкой PS/2 на голом железе).
- `endl` — Манипулятор сброса буфера и переноса строки (`\n`).
- `text;` — Быстрый вывод пустой строки-разделителя в консоль.
- `/n;` — Инструкция принудительного переноса строки в консоли.
- `input(prompt, target_var)` — Вывод подсказки и ожидание одиночного ввода (до первого пробела).
- `input.getline(prompt, target_var)` — Считывание строки целиком вместе с пробелами (до нажатия Enter).

### Строковые операции (String API)
- `len(str)` — Возвращает длину строки или количество элементов в массиве.
- `upper(str)` — Перевод всех символов строки в верхний регистр.
- `lower(str)` — Перевод всех символов строки в нижний регистр.
- `substr(str, start, length)` — Извлечение подстроки фиксированной длины начиная с позиции start.
- `replace(str, search, replacement)` — Замена всех вхождений подстроки search на replacement.
- `contains(str, substr)` — Проверка наличия подстроки (возвращает 1 при наличии, 0 при отсутствии).
- `trim(str)` — Удаление начальных и завершающих пробелов и переводов строк.
- `to_str(number)` — Преобразование числа в строковый тип.
- `to_num(str)` — Парсинг строки в числовое значение с плавающей точкой.
- `typeof(var)` — Определение типа переменной ("string", "number", "struct", "array").

### Системные вызовы и взаимодействие с Windows
- `clear()` / `cls()` — Аппаратная очистка экрана терминала.
- `color(name)` — Установка цвета текста консоли ("green", "cyan", "red", "yellow", "white", "blue", "gray").
- `time()` — Текущий UNIX-таймстемп в секундах.
- `clock_ms()` — Значение монотонного аппаратного счётчика времени в миллисекундах.
- `beep(freq, dur)` — Воспроизведение системного звукового сигнала указанной частоты и длительности.
- `msgbox(title, text)` — Отображение стандартного модального окна Windows (MessageBox).
- `system(command)` — Выполнение команды в оболочке операционной системы (cmd.exe).
- `exists(filepath)` — Проверка физического наличия файла по пути (1 или 0).
- `remove(filepath)` — Удаление файла с диска (возвращает 1 при успехе).

### Базовая математика
- `pow(base, exp)` — Возведение числа base в степень exp.
- `floor(val)` — Округление числа вниз до ближайшего меньшего целого.
- `ceil(val)` — Округление числа вверх до ближайшего большего целого.
- `clamp(val, min_val, max_val)` — Ограничение числа в заданном диапазоне от min_val до max_val.
- `abs(val)` — Модуль (абсолютная величина) числа.
- `sqrt(val)` — Квадратный корень из неотрицательного числа.
