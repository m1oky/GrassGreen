# Библиотека !mmio! (!io!, !hw!) — Аппаратный доступ к памяти и портам

- `mmio_read8(addr)` — Чтение 8-битного байта по физическому адресу памяти.
- `mmio_read16(addr)` — Чтение 16-битного слова по физическому адресу памяти.
- `mmio_read32(addr)` — Чтение 32-битного двойного слова по физическому адресу памяти.
- `mmio_read64(addr)` — Чтение 64-битного значения по физическому адресу памяти.
- `mmio_write8(addr, val)` — Запись 8-битного байта по физическому адресу памяти.
- `mmio_write16(addr, val)` — Запись 16-битного слова по физическому адресу памяти.
- `mmio_write32(addr, val)` — Запись 32-битного двойного слова по физическому адресу памяти.
- `mmio_write64(addr, val)` — Запись 64-битного значения по физическому адресу памяти.
- `inb(port)` / `io_in8(port)` — Чтение 8-битного байта из аппаратного порта ввода-вывода x86.
- `inw(port)` / `io_in16(port)` — Чтение 16-битного слова из аппаратного порта ввода-вывода x86.
- `inl(port)` / `io_in32(port)` — Чтение 32-битного двойного слова из аппаратного порта x86.
- `outb(port, val)` / `io_out8(port, val)` — Запись 8-битного байта в аппаратный порт ввода-вывода x86.
- `outw(port, val)` / `io_out16(port, val)` — Запись 16-битного слова в аппаратный порт ввода-вывода x86.
- `outl(port, val)` / `io_out32(port, val)` — Запись 32-битного двойного слова в аппаратный порт x86.
- `memory_barrier()` — Полный аппаратный барьер сериализации памяти (инструкция mfence).
- `read_barrier()` — Барьер чтения памяти (инструкция lfence).
- `write_barrier()` — Барьер записи памяти (инструкция sfence).
- `volatile` — Спецификатор переменной, предотвращающий кеширование в регистрах при обращении к аппаратным регистрам.
