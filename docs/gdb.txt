** УПРАВЛЕНИЕ БАЗОЙ ДАННЫХ И ЗАПРОСЫ (GSE v3.0) **

!database! = Обязательный заголовок в первой строке каждого файла базы данных (.gdb).

--- УПРАВЛЕНИЕ ФАЙЛОМ БАЗЫ И ТАБЛИЦАМИ ---
db_open(путь) = Подключает и загружает файл базы данных (например: db_open(storage.gdb)).
db_save(путь) = Сохраняет все текущие ключи и таблицы из оперативной памяти на диск в файл .gdb.
db_autosave(1/0) = Включает автоматическое сохранение базы на диск при каждом изменении любого ключа.
db_backup(путь) = Создаёт резервную копию базы данных (.bak), чтобы не потерять профили и настройки.
db_export_json(путь) = Выгружает всю базу данных в стандартный формат .json для внешних лаунчеров и сайтов.
table(имя) / end-table = Создаёт отдельную таблицу (секцию) внутри базы (например: table(network) или table(users)).

--- ОПЕРАЦИИ С ДАННЫМИ (CRUD) ---
db_set(ключ, значение) = Записывает или обновляет значение по ключу.
db_get(ключ) = Достаёт значение ключа из базы данных.
db_del(ключ) = Полностью удаляет ключ из базы данных и очищает его из кэша.
db_has(ключ) = Проверяет, существует ли ключ в базе (возвращает 1 если есть, 0 если нет).
db_inc(ключ, число) = Увеличивает числовое значение ключа на заданное число (удобно для счётчика входов, пинга или ОЗУ).
db_dec(ключ, число) = Уменьшает числовое значение ключа.
db_clear() = Полностью очищает текущую базу данных в памяти.

--- БЕЗОПАСНОСТЬ, АВТО-ПОЛЯ И КРИПТОГРАФИЯ ---
last_log(auto) = Автоматически считывает текущую дату и время Windows и записывает в last_log().
auth_token_hash(auto) = Автоматически генерирует уникальный 64-битный хэш сессии для защиты профиля.
db_hash(строка) = Превращает любую строку или пароль в необратимый крипто-хэш (формата gg_...).
db_encrypt(ключ) = Шифрует значение ключа алгоритмом XOR-HEX, чтобы его нельзя было прочитать в Блокноте.
db_decrypt(ключ) = Расшифровывает защищённый ключ обратно в обычный текст.

--- ДОПОЛНИТЕЛЬНЫЕ СИСТЕМНЫЕ И ПРОФИЛЬНЫЕ КЛЮЧИ ---
user_uuid() = Уникальный идентификатор профиля игрока или пользователя.
user_role() = Уровень доступа профиля (user, moderator, admin, developer).
sys_cpu_threads() = Количество выделенных потоков процессора под задачу или игру.
sys_window_mode() = Режим отображения окна (windowed, borderless, fullscreen).
net_dns_server() = Кастомный DNS-сервер для обхода блокировок и ускорения ответов (например, 1.1.1.1).
net_mtu_size() = Размер пакета MTU для тонкой настройки сетевого туннеля.
