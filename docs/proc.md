# Библиотека !proc! — Управление процессами Windows

- `proc_find(name)` — Поиск процесса по имени исполняемого файла, возвращает его PID (или -1, если не найден).
- `proc_kill(pid)` — Принудительное завершение процесса по его числовому идентификатору PID (возвращает 1 при успехе).
- `proc_mem(pid)` — Определение объема оперативной памяти, занятой указанным процессом (в МБ).
- `proc_exists(pid)` — Проверка активности процесса с заданным PID в операционной системе (1 или 0).
- `proc_list()` — Получение списка всех активных процессов операционной системы в виде строки.
