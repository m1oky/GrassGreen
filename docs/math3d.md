# Модуль !math3d! — 3D-математика и линейная алгебра

Модуль `!math3d!` предоставляет высокопроизводительные математические примитивы для трёхмерной графики, игр и симуляций на чистом C++ без зависимостей от операционной системы (полная поддержка Windows, Linux и Bare-Metal).

---

## Векторные операции (vec3)

- `v3_add(a, b)` — поэлементное сложение векторов `(x, y, z)`.
- `v3_sub(a, b)` — вычитание вектора b из a.
- `v3_mul(a, scalar)` — умножение вектора на число.
- `v3_dot(a, b)` — скалярное произведение.
- `v3_cross(a, b)` — векторное произведение (нормаль к плоскости).
- `v3_length(a)` — евклидова длина вектора.
- `v3_normalize(a)` — нормализация вектора до единичной длины.
- `v3_lerp(a, b, t)` — линейная интерполяция между векторами с фактором t [0..1].

---

## Матричные преобразования (mat4)

- `m4_identity()` — создание единичной матрицы 4x4.
- `m4_translate(v3)` — матрица перемещения в пространстве.
- `m4_rotate(angle_rad, axis_v3)` — матрица вращения вокруг произвольной оси на угол в радианах.
- `m4_scale(v3)` — матрица масштабирования по осям.
- `m4_look_at(eye, target, up)` — матрица вида камеры (View Matrix).
- `m4_perspective(fov_rad, aspect, near, far)` — матрица перспективной проекции.
- `m4_mul(m1, m2)` — перемножение двух матриц преобразования.
