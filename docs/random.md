# Библиотека !random! — Генератор случайных величин

- `random()` — Генерация случайного числа.
- `random_txt(lang)` — Генерация строки из случайных букв (параметр языка "rus" или "en").
- `stop_random()` — Приостановка генератора на определенном значении (фиксация зерна псевдослучайной последовательности).
- `play_random()` — Возобновление генерации случайных величин.
- `rand_int(min, max)` — Генерация случайного целого числа в заданном интервале.
- `rand_float(min, max)` — Генерация случайного числа с плавающей точкой в диапазоне от min до max.
