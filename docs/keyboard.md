# Библиотека `!keyboard!` (Контроллер клавиатуры PS/2)

Библиотека **`!keyboard!`** (алиасы: `!kbd!`, `!ps2!`, `!PS2Keyboard!`) предоставляет встроенный аппаратно-независимый инструментарий для взаимодействия с контроллером клавиатуры (порты 8042 `0x60` и `0x64`).

Библиотека избавляет от рутинного низкоуровневого кода: опрос портов, чтение скан-кодов PS/2 Set 1, распознавание клавиш-модификаторов (Shift, Caps Lock, Ctrl, Alt) и построчный ввод текста с поддержкой Backspace реализуются буквально в несколько строк.

Работает как в автономном режиме голого железа (bare-metal ядра), так и в среде виртуальной машины GrassVM.

---

## Подключение библиотеки

```cpp
!GrassGreen!
!keyboard!

int main() {
    // Код работы с клавиатурой
    return 0;
}
```

---

## Словарь функций

### 1. Низкоуровневый опрос контроллера
- **`kbd_has_key()`** / **`kbd_available()`** `-> bool`
  Проверяет наличие готового скан-кода в выходном буфере контроллера (бит 0 регистра статуса порта `0x64`). Возвращает `1`, если клавиша нажата, иначе `0`. Не блокирует поток выполнения.
- **`kbd_read_scancode()`** `-> u8`
  Считывает байт скан-кода из порта данных `0x60`. Возвращает сырой код (Make-код при нажатии или Break-код с битом 0x80 при отпускании). Если буфер пуст, возвращает `0`.
- **`kbd_get_scancode()`** `-> u8`
  Блокирующее чтение: ожидает физического нажатия клавиши и возвращает скан-код нажатия (Make-код).

### 2. Преобразование скан-кодов и символы
- **`kbd_scancode_to_char(take scancode)`** `-> string`
  Преобразует 8-битный скан-код PS/2 Set 1 в символ ASCII с учетом текущего состояния Shift и Caps Lock.
- **`kbd_scancode_name(take scancode)`** `-> string`
  Возвращает человекочитаемое имя клавиши (например, `"Enter"`, `"Backspace"`, `"Escape"`, `"LeftShift"`, `"Space"`, `"F1"`).

### 3. Высокоуровневый ввод текста
- **`kbd_getc()`** `-> string`
  Блокирующее ожидание и чтение одного символа с клавиатуры.
- **`kbd_poll()`** `-> string`
  Неблокирующий опрос: возвращает строку с символом нажатой клавиши или пустую строку `""`, если ничего не нажато.
- **`kbd_read_line()`** `-> string`
  Считывает строку символов до нажатия Enter (`\n`), автоматически отображая эхо-печать в консоли и корректно обрабатывая стирание символов клавишей Backspace.

### 4. Состояние модификаторов
- **`kbd_is_shift()`** `-> bool` — зажат ли левый или правый Shift.
- **`kbd_is_caps()`** `-> bool` — включен ли режим Caps Lock.
- **`kbd_is_ctrl()`** `-> bool` — зажат ли Ctrl.
- **`kbd_is_alt()`** `-> bool` — зажат ли Alt.
- **`kbd_is_key_pressed(take scancode)`** `-> bool` — нажата ли конкретная клавиша в данный момент.

### 5. Команды контроллера 8042
- **`kbd_leds(take caps, take num, take scroll)`** `-> void`
  Управляет светодиодами клавиатуры, отправляя команду `0xED` в контроллер.
- **`kbd_reset()`** `-> void`
  Отправляет команду программного сброса клавиатуры `0xFF`.
- **`kbd_self_test()`** `-> bool`
  Запускает самодиагностику контроллера (команда `0xAA`). Возвращает `1` при успешном прохождении (`0x55`).

## Пример использования

```cpp
!GrassGreen!
!keyboard!

int main() {
    gout << "=== ТЕСТ КОНТРОЛЛЕРА КЛАВИАТУРЫ ===" << endl;
    gout << "Введите ваше имя: ";

    // Построчный ввод с поддержкой Backspace
    take name = kbd_read_line();
    gout << "Привет, " << name << "!" << endl;

    gout << "Нажмите любую клавишу для выхода..." << endl;
    take sc = kbd_get_scancode();
    take key_name = kbd_scancode_name(sc);
    gout << "Нажата клавиша: " << key_name << " (код 0x" << sc << ")" << endl;

    return 0;
}
```
