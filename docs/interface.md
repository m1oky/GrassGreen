# Библиотека !interface! — Универсальный графический интерфейс (GUI) & VD+ Engine

> **Статус:** Модернизация ядра интерфейса v4.0 (Графический движок VD+ — Video Graphics Plus)  
> **Назначение:** Создание высокопроизводительных, красивых и адаптивных графических приложений, IDE и визуальных оболочек операционной системы без внешних зависимостей.  
> **Стиль:** Графика уровня современного CSS (Tailwind/Figma): субпиксельное сглаживание углов, линейные градиенты, многослойные тени (Box Shadow), эффект матового стекла (Aero/Mica), неоновое свечение (Glow), векторная отрисовка SVG, поддержка любых форматов видео и настраиваемая шапка окна.

---

## 1. Управление окном, шапкой и поверхностью (Window & Surface Management)

- `surface("auto" | "windowed" | "freestanding" | "borderless")` — Универсальный движок отображения поверхности:
  - `"auto"` (по умолчанию) — Автоматическое определение среды: активирует `windowed` внутри Windows/Linux и `freestanding` на голом железе без ОС.
  - `"windowed"` — Нативная системная коробка ОС Windows с заголовком и кнопками. Вся графика рендерится в виртуальный пиксельный буфер VD+ и за 1 вызов проецируется внутрь окна (`BitBlt`).
  - `"freestanding"` — Голый фреймбуфер (Bare-Metal). Никаких системных окон и вызовов Win32. Прямая запись пикселей в физическую видеопамять VESA/GOP через модуль `GrassMMIO` на весь экран.
  - `"borderless"` — Кастомный оверлей внутри ОС без системной рамки Windows, с фирменными изумрудными кнопками управления и эффектом матового стекла.
- `auto_size_display()` — Автоматическое определение разрешения и масштабирования дисплея (High-DPI / 2K / 4K):
  - Активирует режим Per-Monitor DPI Awareness V2 на уровне ОС, отключая билинейное растяжение DWM (полностью устраняет эффект размытой и «плывущей» картинки).
  - Автоматически считывает системный DPI (100%, 125%, 150%, 200%) и масштабирует размеры окон, шрифты (`font-size`), радиусы скруглений (`radius`), тени (`shadow`), неоновые свечения (`glow`) и отступы (`pad`).
  - Автоматически центрирует окно на мониторе пользователя.
- `border-radius-app(pixels)` — Скругление углов всего окна приложения (например, `border-radius-app(16)`):
  - Полностью исключает белую некрасивую системную обводку Windows 10/11 за счет автоматического перевода окна в ультрагладкий фреймлесс-режим с естественной тенью `CS_DROPSHADOW`.
  - В Windows 11 задействует аппаратный DWM Corner Preference API.
- `header("dots" | "mac" | "modern" | "glass" | "emerald" | "none" | "native")` — Выбор предустановленного стиля шапки окна:
  - `"dots"` / `"mac"` — Стиль macOS: 3 цветные круглые точки (красная, желтая, зеленая). При наведении мыши внутри точек отображаются символы действий ('x', '-'). Красная точка закрывает окно, желтая сворачивает, зеленая разворачивает на весь экран.
  - `"modern"` (по умолчанию при скруглении) — Тонкая стильная шапка в темной палитре со скругленными кнопками Windows 11 Свернуть `[-]` и Закрыть `[X]`.
  - `"glass"` — Настоящее полупрозрачное акриловое матовое стекло шапки с зеркальным бликом и разделителем. При этом холст самого окна остается насыщенным и непрозрачным (`#09090b`).
  - `"emerald"` — Фирменный градиент GrassGreen с изумрудным свечением.
  - `"none"` — Окно без системной рамки и шапки (Frameless). При этом окно свободно и плавно перетаскивается мышью за любую пустую область холста!
  - `"native"` — Классическая стандартная рамка Windows.
- `header-color(hex)` — Индивидуальный цвет фона шапки окна (например, `header-color("#0f172a")`).
- `header-text-color(hex)` — Цвет текста названия в шапке (например, `header-text-color("#22c55e")`).
- `header-height(pixels)` — Высота панели заголовка (по умолчанию 38px).
- `header-buttons("all" | "close" | "none")` — Набор кнопок управления в шапке.
- `header-buttons-pos("left" | "right" | "center")` / `header-buttons("left" | "right")` — Расположение кнопок управления в шапке:
  - `"left"` — Кнопки размещаются в левой части шапки (по умолчанию для `dots` / macOS).
  - `"right"` — Кнопки размещаются в правой части шапки (по умолчанию для `modern`, `emerald`, `glass`).
- `header-buttons-offset(pixels)` — Точное смещение кнопок шапки по горизонтали в пикселях (например, `header-buttons-offset(20)` сдвигает кнопки вправо на 20px, `-10` сдвигает влево).
- `header-title-align("left" | "center" | "right")` / `header-align(...)` — Выравнивание названия окна в шапке.
- **Интерактивное перемещение кнопок шапки:** в запущенном приложении кнопки можно свободно перетаскивать мышью влево и вправо прямо на лету: достаточно зажать `Shift` или `Ctrl` при клике, либо перетаскивать правой кнопкой мыши!
- `fullscreen()` / `fullscrean()` — Открытие приложения сразу на весь экран (максимизированный режим с сохранением красивой шапки, идеально для IDE и дашбордов).
- `topmost(true | false)` / `topmost()` — Закрепление окна поверх всех окон рабочего стола Windows (Always on Top).
- `z-index(number)` / `layer(number)` — Управление слоем окна: при `z-index(1)` и выше окно закрепляется поверх остальных окон.
- **Всплытие окна при клике (Z-Order Auto-Surfacing):** при клике мышью в любую область окна (холст, шапка, элементы, рамка) окно гарантированно и мгновенно активируется и всплывает поверх всех остальных открытых окон на рабочем столе (`WM_MOUSEACTIVATE`, `BringWindowToTop`, `SetForegroundWindow`).
- `layout("center")` / `align-all("center")` — Автоматическое адаптивное центрирование всех элементов окна при любом размере экрана (включая 2K и 4K).
- `window-border(width, hex)` — Тонкая аккуратная рамка вокруг всего скругленного окна (например, `window-border(1, "#27272a")`).
- `title("Текст")` — Заголовок окна в шапке и на панели задач.
- `size(width, height)` — Размеры окна в пикселях.
- `color(hex)` — Фоновый цвет холста окна (например, `#09090b`).
- `theme("dark" | "light" | "emerald" | "cyber")` — Глобальная цветовая палитра.
- `glass(true | false)` — Включение аппаратного эффекта матового стекла окна.
- `fon("path/to/image")` — Фоновое изображение холста.
- `iconP("path/to/icon.ico")` — Системная иконка окна и панели задач.
- `show()` — Запуск цикла событий и отображение окна.

## 2. Плавное изменение размера окна и максимизация (Window Resizing & Maximizing)

- **Плавный ресайз окна мышью:**
  - Окно можно плавно растягивать за любой край (левый, правый, верхний, нижний) или любой из 4-х углов (8px зона захвата).
  - Отображаются системные двухсторонние стрелки изменения размера (`↔`, `↕`, `↗`, `↖`).
  - При ресайзе окно не мерцает (`WM_ERASEBKGND` = 1, двойная буферизация VD+), а элементы с выравниванием `middle()` автоматически динамически центрируются.
- **Разворачивание окна на весь экран (Зеленая точка / Квадрат `[□]` / Двойной клик):**
  - Клик по зеленой кнопке в стиле macOS или по кнопке `[□]` в стиле Windows разворачивает окно на весь экран без телепортации и артефактов.
  - Повторный клик мгновенно восстанавливает исходный размер и положение окна по центру экрана.
  - При максимизации автоматически учитывается панель задач Windows (панель не перекрывается), а скругление углов временно отключается, чтобы не было зазоров по краям экрана.
  - Двойной клик по свободной области шапки также переключает окно между развернутым и обычным состоянием.
- **Поддержка Aero Snap:** окно можно перетащить к верхней кромке экрана монитора для мгновенного разворачивания или потянуть вниз для восстановления.

## 3. Стилизация элементов уровня CSS (VD+ Styling)

- `radius(pixels)` — Идеальное математическое скругление углов без артефактов и засечек (для `button`, `enter`, карточек). Для `label` по умолчанию `0` (чистый текст).
- `border(width, hex)` — Четкая субпиксельная рамка без разрывов в углах (например, `border(1, "#27272a")`).
- `shadow(blur, hex)` — Многослойная мягкая CSS-тень глубины (Box Shadow).
- `glow(hex, radius)` — Акцентное неоновое свечение (Emerald Glow).
- `gradient(color1, color2, angle)` — Линейный CSS-градиент заливки кнопок.
- `hover-color(hex)` — Цвет фона при наведении курсора.
- `active-color(hex)` — Цвет фона при нажатии мышью.
- `text-color(hex)` — Цвет шрифта текста.
- `font-size(pixels)` — Размер шрифта.
- `font-style("FontName")` — Гарнитура шрифта (например, `"Segoe UI"`, `"JetBrains Mono"`).
- `font-weight("bold" | "normal")` — Начертание шрифта (жирный или обычный).
- `pad(pixels)` — Внутренний отступ текста от границ элемента.

## 4. Динамические частицы и фоновое свечение (VD+ Particle Engine)

- `particles(count, color_hex, speed)` — Генератор живых парящих частиц в фоне окна (60 FPS):
  - Создает эффект глубокого живого пространства с мерцающими светлячками/частицами.
  - Каждая частица имеет независимую скорость дрейфа, плавную синусоидальную пульсацию прозрачности и размер.
  - Пример: `particles(35, "#22c55e", 1.0);`

## 5. CSS Анимации элементов (VD+ Animation Engine)

- `animate("pulse" | "glow" | "fade-in" | "slide-up", duration_ms)` — Анимация для кнопок, текстов и полей ввода:
  - `"pulse"` — Плавная дыхательная гармоническая пульсация размера элемента (без артефактов и дрожания).
  - `"glow"` — Пульсирующий ореол неонового свечения вокруг элемента.
  - `"fade-in"` — Плавное проявление элемента из прозрачности при открытии или смене вкладки.
  - `"slide-up"` — Плавный выплыв снизу вверх с плавным нарастанием прозрачности.
- **Дышащая неоновая каретка ввода:**
  - В поле `enter` каретка синхронизирована с типографикой GDI+ субпиксельно (`GenericTypographic` + trailing spaces) и гарантированно не залезает на буквы.
  - Каретка пульсирует мягким неоновым изумрудным светом вместо резкого мигания 1/0.

## 6. Система вкладок (Tabs System: tab / switch)

- `tab = "имя" { ... }` или `tab "имя" { ... }` — Создание изолированного блока элементов, принадлежащих определенной вкладке. Элементы вне блоков вкладок по умолчанию относятся к вкладке `"main"`.
- `click-switch("имя_вкладки")` — Свойство кнопки, переключающее активную вкладку при клике:
  ```grass
  button "В настройки" {
      click-switch("settings");
  }
  ```
- `switch("имя_вкладки")` / `switch_tab("имя_вкладки")` — Переключение активной вкладки программно из кода GrassGreen или внутри кнопки.
- При переключении вкладок элементы плавно анимируются в соответствии со своими настройками `animate(...)`.

## 4. Поддержка мультимедиа: Векторные SVG, Фото и Видео

### Векторный рендерер SVG
- `svg "path/to/icon.svg" { window-ob(x, y); size(w, h); }`
- `icon "path/to/icon.svg" { window-ob(x, y); size(w, h); }`
Встроенный быстрый движок VD+ автоматически разбирает SVG-файлы:
- Пути `<path d="...">` (команды `M`, `L`, `H`, `V`, `C`, `S`, `Q`, `Z`).
- Геометрию: `<rect>`, `<circle>`, `<ellipse>`, скругления `rx`, заливки `fill`, обводки `stroke`.
- Линейные градиенты `<linearGradient>`.
- Масштабирует векторную графику под любое разрешение (2K/4K) с идеальной резкостью без пикселизации.

### Поддержка всех форматов изображений
- `icon "image.png"`
- `icon "image.jpg"`
- Поддерживаются: `.svg`, `.png`, `.jpg`, `.jpeg`, `.bmp`, `.ico`, `.gif`, `.tiff`, `.webp`.

### Поддержка любых форматов видео
- `video "media/intro.mp4" { window-ob(100, 100); size(480, 270); }`
- Поддерживаются любые форматы и кодеки: `.mp4`, `.avi`, `.mkv`, `.wmv`, `.webm`, `.mov`.
- Видео аппаратно проецируется напрямую внутрь окна приложения по заданным координатам.

## 5. Элементы управления (Widgets)

- `button "Текст" { ... }` — Кнопка с градиентами, бликом, свечением и hover-эффектами.
- `enter "Текст" { ... }` — Поле ввода с плавным фокусом, мигающей кареткой, плейсхолдером и скруглением без артефактов.
  - `placeholder("Подсказка...")` — Текст подсказки.
  - `placeholder-color("#71717a")` — Цвет неактивного текста подсказки.
- `label "Текст" { ... }` — Текстовая надпись. Если задать `radius(8)` или `button-color(hex)`, автоматически оформляется как стильная карточка/бейдж.
- `clock "формат" { ... }` / `clock { ... }` — Виджет живых часов (Clock Widget).
  - Автоматически обновляется раз в секунду в фоновом 60 FPS таймере без нагрузки на CPU и без необходимости писать циклы обновления вручную.
  - Поддерживает форматы: `"HH:mm:ss"` (по умолчанию), `"HH:mm"`, `"date"`, `"datetime"`, либо шаблон с токенами `HH`, `mm`, `ss`, `YYYY`, `MM`, `DD`.
  - Отлично размещается в углу шапки или окна (например, `window-ob(590, 8); right();`).
  - Поддерживает шрифты (`font-size`, `font-style`, `font-weight`), неоновое свечение `glow(...)`, карточки и тени.
- `click-ob(input_id, label_id)` — Мгновенная передача введенных данных из поля ввода в текстовый блок по клику кнопки.

## 6. Пример: Современный интерфейс со скруглением и кастомной шапкой

```grass
!GrassGreen!
!interface!

int main() {
    window {
        auto_size_display();
        border-radius-app(16);
        header("modern");
        header-color("#0f172a");
        header-text-color("#22c55e");
        title("GrassGreen VD+ Modern Studio");
        size(720, 500);
        color("#09090b");

        label "GrassGreen VD+ Video Graphics Engine" {
            window-ob(50, 60);
            size(620, 36);
            middle();
            text-color("#22c55e");
            font-size(22);
            glow("#22c55e", 8);
        }

        enter "" {
            id(user_input);
            window-ob(160, 140);
            size(400, 42);
            placeholder("Введите текст для обработки...");
            radius(10);
            border(1, "#27272a");
            text-color("#f4f4f5");
            font-size(15);
        }

        button "Применить эффект" {
            id(btn_action);
            window-ob(235, 210);
            size(250, 44);
            gradient("#22c55e", "#16a34a", 90);
            hover-color("#4ade80");
            active-color("#15803d");
            glow("#22c55e", 10);
            radius(10);
            text-color("#ffffff");
            font-size(15);
            click-ob(user_input, lbl_result);
        }

        label "Ожидание ввода данных..." {
            id(lbl_result);
            window-ob(110, 280);
            size(500, 46);
            middle();
            radius(8);
            border(1, "#27272a");
            button-color("#18181b");
            text-color("#f4f4f5");
            font-size(15);
        }
    }
    return 0;
}
```
