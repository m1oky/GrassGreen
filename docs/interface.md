# Библиотека !interface! — Графический интерфейс Windows (GUI)

- `window()` — Создание главного окна приложения.
- `title()` — Задание названия и заголовка окна.
- `size()` — Установка размеров окна в пикселях (ширина, высота).
- `color()` — Изменение цвета фона окна.
- `theme` — Выбор темы оформления окна (dark / light).
- `glass` — Включение эффекта прозрачности (Aero Glass / Mica).
- `fon()` — Установка фонового изображения окна.
- `show` — Отображение созданного окна и элементов на экране.
- `clear` — Очистка экрана или содержимого формы.
- `label` — Создание текстовой плашки или информационного блока.
- `enter()` — Создание поля ввода текста.
- `button` — Создание интерактивной кнопки.
- `button-color()` — Изменение цвета кнопки.
- `id()` — Присвоение числового или буквенного идентификатора элементу.
- `name()` — Присвоение строкового имени элементу интерфейса.
- `window-ob()` — Точное позиционирование элемента по координатам X и Y.
- `size-top()` — Задание высоты элемента в пикселях.
- `middle()` — Выравнивание объекта по горизонтальному центру.
- `left()` — Выравнивание объекта по левому краю.
- `right()` — Выравнивание объекта по правому краю.
- `text-color()` — Установка цвета текста элемента.
- `font-size()` — Задание размера шрифта.
- `font-style()` — Выбор гарнитуры шрифта текста (например, "Segoe UI").
- `radius()` — Закругление углов элемента по его имени или id.
- `pad()` — Внутренние отступы текста внутри элемента или кнопки.
- `shadow()` — Включение эффекта отбрасывания тени элементом.
- `icon()` — Добавление изображения или значка.
- `iconP()` — Установка иконки превью самого приложения в заголовке окна.
- `video()` — Встраивание видеоплеера в окно.
- `click-ob()` — Привязка обработчика нажатия кнопки к действию или функции.
- `switch()` — Переключение на другое состояние или событие интерфейса.
- `animate-..` — Запуск анимации для элемента с указанным именем или id.
- `run()` — Запуск внешних исполняемых файлов (.exe) из интерфейса.
