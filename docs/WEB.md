# Библиотека !GrassWeb! — Веб-движок и транслятор нового поколения

> **Статус:** Модернизация веб-ядра v4.3  
> **Назначение:** Создание современных адаптивных веб-интерфейсов, посадочных страниц (Landing Page), дашбордов и интерактивных веб-приложений без внешних фреймворков и зависимостей (Zero-dependency HTML5 + CSS3 + Vanilla JS транслятор).  
> **Особенности:** Поддержка Flexbox, CSS Grid, карточек, таблиц, Glassmorphism, неонового свечения, анимаций и встроенного скриптового движка сценариев `script-start` ... `script-end`.

---

## 1. Структура страницы и HTML-элементы

В GrassWeb поддерживается как классический синтаксис парных блоков `-start` / `-end`, так и компактная блочная форма со скобками `{ ... }`.

### 1.1. Структурные контейнеры
- `page-start` / `page-end` (или `page { ... }`) — корневой контейнер страницы (`.grass-page`). Обеспечивает центрирование и базовую структуру документа.
- `header-start` / `header-end` (или `header { ... }`) — шапка сайта (`<header>`). По умолчанию оформлена с полупрозрачным фоном, разделителем и поддержкой Flexbox.
- `footer-start` / `footer-end` (или `footer { ... }`) — подвал сайта (`<footer>`) с автоматическим отступом сверху.
- `nav-start` / `nav-end` (или `nav { ... }`) — навигационная панель (`<nav>`) для группировки ссылок и кнопок.
- `section-start` / `section-end` (или `section { ... }`) — логическая секция страницы (`<section>`) с адаптивной максимальной шириной 1200px.
- `card-start` / `card-end` (или `card { ... }`) — готовая карточка контента (`.grass-card`) с аккуратным скруглением, темным фоном, мягкой тенью и эффектом приподнятия при наведении мыши.
- `box-start` / `box-end` (или `div-start` / `div-end` / `box { ... }`) — универсальный блок (`<div>`).
- `row-start` / `row-end` — гибкая строка (Flexbox Row) для горизонтального размещения дочерних элементов.
- `col-start` / `col-end` — гибкая колонка (Flexbox Column) для вертикального размещения элементов.

### 1.2. Контентные элементы
- **Заголовки и текст:**
  - `title = "Текст"` или `h1 = "Текст"` — главный заголовок `<h1>` (34px, жирный шрифт).
  - `h2 = "Текст"` — заголовок второго уровня `<h2>` (26px).
  - `h3 = "Текст"` — заголовок третьего уровня `<h3>` (20px).
  - `text = "Текст"` или `p = "Текст"` — текстовый абзац `<p>` (16px, межстрочный интервал 1.6).
  - `G1 .. G5 "Текст"` — заголовки фиксированных размеров GrassWeb (от 15px до 46px).
- **Ссылки и изображения:**
  - `link(url) = "Текст ссылки"` — гиперссылка `<a>`.
  - `img(url)` или `image(url)` — изображение `<img>` с адаптивной шириной.
- **Элементы форм:**
  - `input = "Плейсхолдер"` (синоним `enter = ...`) — поле ввода текста или пароля.
  - `textarea = "Плейсхолдер"` — многострочное текстовое поле с возможностью вертикального растяжения.
  - `select(Опция1, Опция2, ...)` (синоним `drop-list(...)`) — выпадающий список вариантов `<select>`.
  - `btn = "Текст"` (синоним `button = ...`) — стилизованная интерактивная кнопка `<button>`.
  - `checkbox = "Текст надписи"` — флажок с текстом.
  - `slider(min, max, default)` — ползунок выбора числового диапазона.
- **Таблицы:**
  - `table-start` / `table-end` — таблица с готовыми границами и подсветкой строк при наведении (`.grass-table`).
  - `tr-start` / `tr-end` (или `row-start` / `row-end` внутри таблицы) — строка таблицы `<tr>`.
  - `th = "Текст"` или `th(Текст)` — заголовочная ячейка таблицы `<th>`.
  - `td = "Текст"` или `td(Текст)` — обычная ячейка таблицы `<td>`.
- **Медиа-фон:**
  - `video-bg(url)` — фоновое зацикленное видео во весь экран страницы с легким затемнением.
- **Именование элементов для скриптов:**
  - `<name>/id_элемента` или `id(id_элемента)` — привязка уникального идентификатора (указывается перед элементом).

## 2. Стилизация и раскладка: Flexbox & Grid

Модификаторы стилей объявляются **перед** элементом или контейнером, к которому они применяются:

### 2.1. Раскладка (Layout)
- `flex()` / `flex(row)` — включение горизонтальной Flexbox-раскладки с переносом строк.
- `flex(column)` / `flex(col)` — вертикальная Flexbox-раскладка.
- `flex(center)` — центрирование дочерних элементов по обеим осям.
- `grid(3)` — включение сетки CSS Grid на 3 равные колонки (`repeat(3, 1fr)`).
- `grid("1fr 2fr 1fr")` — сетка с кастомным распределением долей.
- `gap(20)` — расстояние между дочерними элементами в flex/grid (в пикселях).
- `align(center | left | right)` — выравнивание текста внутри элемента.

### 2.2. Отступы и геометрия
- `pad(20)` (или `space(20)`) — внутренний отступ `padding` в пикселях.
- `pad(10, 20)` — внутренний отступ: 10px сверху/снизу и 20px слева/справа.
- `margin(15)` (или `space-out(15)`) — внешний отступ `margin`.
- `width(100%)` / `width(400)` — ширина элемента (поддерживаются `%`, `px`, `vw`).
- `height(50)` / `height(100vh)` — высота элемента.
- `radius(12)` (или `round-ob(12)`) — скругление углов (`border-radius: 12px`).
- `circle` / `circle()` — превращение элемента в правильный круг (`border-radius: 50%`).

### 2.3. Цвета, фон и эффекты
- `color("#22c55e")` — цвет текста.
- `bg("#09090b")` — цвет фона.
- `grad("#22c55e", "#16a34a")` — линейный градиент фона под углом 135 градусов.
- `border(1, "#27272a")` — толщина и цвет рамки.
- `shadow(20, 0.5)` (или `shadowbox(20, 0.5)`) — мягкая CSS-тень (размытие 20px, прозрачность 0.5).
- `glass(12, 0.08)` / `glass` — аппаратный матовый эффект стекла (Backdrop Blur 12px + легкая полупрозрачность).
- `neon("#00ffcc")` — яркое неоновое свечение границ и текста.
- `thick` — повышенная жирность шрифта (`font-weight: 800`).
- `hover("#15803d")` — изменение цвета фона при наведении курсора мыши.
- `hover("#15803d", "#ffffff")` — смена фона и цвета текста при наведении.
- `anim("pulse" | "float" | "spin" | "shake" | "slide", "1.5s")` (или `animate(...)`) — запуск CSS-анимации.

## 3. Интерактивная логика и события (`script-start` ... `script-end`)

В блоке `script-start` ... `script-end` описывается клиентская интерактивная логика, автоматически транслируемая в нативный JavaScript:

### 3.1. События
- `on-click(id)` ... `end-click` — обработка клика мыши по элементу с указанным ID.
- `on-input(id)` ... `end-input` — отслеживание ввода символов в `input` или движения `slider`.
- `on-hover(id)` ... `end-hover` — реакция на наведение курсора мыши на элемент.
- `on-key("Enter")` ... `end-key` — отслеживание нажатия системной клавиши на клавиатуре.

### 3.2. Таймеры и задержки
- `every(1000)` ... `end-every` — запуск интервала (`setInterval`), выполняющегося каждые N миллисекунд.
- `wait(500)` ... `end-wait` — отложенное выполнение кода (`setTimeout`).

### 3.3. Переменные и условия
- `var(count = 0)` — объявление или изменение глобальной переменной.
- `add-var(count, 1)` — быстрое инкрементирование числовой переменной.
- `chek(условие)` ... `else` ... `end-chek` — ветвление `if (...) { ... } else { ... }`.
  - Внутри выражений поддерживаются функции:
    - `val(id)` — текущее строковое значение поля ввода или ползунка.
    - `is-checked(id)` — флаг отмеченности чекбокса (`true` / `false`).
    - `load(key)` — чтение сохраненного значения из браузерного хранилища `localStorage`.

### 3.4. Динамическое изменение DOM
- `set-text(id, "Текст")` — изменение текстового содержимого элемента (поддерживает интерполяцию `{переменная}`).
- `set-val(id, "Значение")` — программная установка значения в поле ввода.
- `clear-val(id)` — мгновенная очистка поля ввода.
- `repaint-color(id, "#hex")` — изменение цвета текста и неона.
- `repaint-bg(id, "#hex")` — изменение цвета фона элемента или всего `body`.
- `hide(id)` — скрыть элемент (`display: none`).
- `show(id)` — показать элемент.
- `toggle(id)` — переключить видимость элемента.
- `set-img(id, "url")` — динамическая замена картинки.
- `play-anim(id, "shake", "0.5s")` — запуск CSS-анимации на лету.

### 3.5. Хранилище, навигация и диалоги
- `alert("Сообщение")` — всплывающее системное окно браузера.
- `log("Текст")` / `gout << "Текст" << endl` — вывод данных в консоль разработчика `console.log`.
- `save(key, val)` — сохранение данных в постоянное локальное хранилище браузера `localStorage`.
- `go(url)` — переход по внешней или внутренней ссылке.
- `reload()` — перезагрузка страницы.
- `sound(url)` — воспроизведение аудиофайла.

## 4. Полный практический пример: Современный адаптивный лендинг

Ниже приведен готовый пример современного адаптивного веб-сайта с навигацией, Hero-секцией, сеткой карточек CSS Grid, интерактивным калькулятором кликов и формой заказа:

```grass
!GrassGreen!
!GrassWeb!

page-start
    // --- Шапка сайта (Header + Nav) ---
    header-start
        color(#22c55e)
        thick
        h2 = GrassGreen Cloud

        nav-start
            link("#features") = Преимущества
            link("#pricing") = Тарифы
            link("#demo") = Демо
            btn = Личный кабинет
        nav-end
    header-end

    // --- Главный экран (Hero Section) ---
    section-start
        align(center)
        pad(40)
        neon(#00ffcc)
        title = Современные Веб-Интерфейсы на GrassGreen

        color(#a1a1aa)
        pad(10)
        p = Декларативная верстка, аппаратный Glassmorphism, реактивные сценарии и нулевой вес рантайма.

        gap(15)
        flex(center)
        row-start
            bg(#22c55e)
            color(#09090b)
            thick
            btn = Начать работу
            
            glass(12, 0.08)
            border(1, #3f3f46)
            btn = Документация API
        row-end
    section-end

    // --- Сетка карточек с преимуществами (CSS Grid 3 колонки) ---
    grid(3)
    gap(20)
    pad(30)
    section-start
        card-start
            color(#22c55e)
            thick
            h3 = Быстродействие
            color(#d4d4d8)
            p = Мгновенная компиляция исходного кода в чистый HTML5 и CSS3 без медленных сборщиков Webpack и Node.js.
        card-end

        card-start
            color(#38bdf8)
            thick
            h3 = Стили и Flexbox/Grid
            color(#d4d4d8)
            p = Полноценная поддержка адаптивных сеток, расстояний gap, скруглений radius и эффекта матового стекла.
        card-end

        card-start
            color(#f59e0b)
            thick
            h3 = Реактивность
            color(#d4d4d8)
            p = Встроенный скриптовый движок script-start с таймерами every() и коллбэками on-click.
        card-end
    section-end

    // --- Интерактивный блок калькулятора и формы ---
    pad(30)
    section-start
        box-start
            glass(16, 0.06)
            border(1, #27272a)
            radius(16)
            pad(30)
            align(center)

            h2 = Интерактивный счетчик кликов
            
            p = Проверьте работу встроенного JavaScript-транслятора:
            
            <name>/counter_val
            color(#00ffcc)
            thick
            h1 = 0

            gap(15)
            flex(center)
            row-start
                <name>/btn_click
                bg(#16a34a)
                color(#ffffff)
                btn = Кликнуть (+1)

                <name>/btn_reset
                bg(#27272a)
                color(#ef4444)
                btn = Сбросить
            row-end

            pad(20)
            h3 = Заявка на доступ

            <name>/input_name
            input = Ваше имя

            <name>/plan_type
            select(Тариф Начальный, Тариф Профессиональный, Корпоративный)

            <name>/order_comment
            textarea = Комментарий к заявке...

            <name>/btn_send
            bg(#2563eb)
            color(#ffffff)
            btn = Отправить заявку
        box-end
    section-end

    // --- Таблица сравнения характеристик ---
    pad(30)
    section-start
        h2 = Сравнение с традиционным веб-стеком
        table-start
            tr-start
                th = Критерий
                th = React / Vue / Angular
                th = GrassWeb Engine
            tr-end
            tr-start
                td = Размер зависимостей
                td = 200+ МБ (node_modules)
                td = 0 КБ (Встроено в компилятор)
            tr-end
            tr-start
                td = Время сборки проекта
                td = 5 - 30 секунд
                td = < 1 миллисекунды
            tr-end
            tr-start
                td = Сложность синтаксиса
                td = Высокая (JSX, Babel, CSS Modules)
                td = Декларативная и лаконичная
            tr-end
        table-end
    section-end

    // --- Подвал (Footer) ---
    footer-start
        color(#71717a)
        p = © 2026 GrassGreen Compiler. Все права защищены.
    footer-end
page-end

// --- Клиентская скриптовая логика ---
script-start
    var(total_clicks = 0)

    on-click(btn_click)
        add-var(total_clicks, 1)
        set-text(counter_val, {total_clicks})
    end-click

    on-click(btn_reset)
        var(total_clicks = 0)
        set-text(counter_val, 0)
    end-click

    on-click(btn_send)
        alert(Благодарим за интерес! Ваша заявка принята.)
    end-click
script-end
```
