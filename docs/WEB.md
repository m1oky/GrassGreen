# Библиотека !GrassWeb! — Фронтенд-разработка и логика веб-страниц

- `script-start` / `script-end` — Блок декларативной логики для трансляции в браузерный сценарий.
- `id(имя):` — Выбор целевого элемента DOM по его идентификатору.
- `on-click(id)` / `end-click` — Обработчик события клика мыши по указанному элементу.
- `on-input(id)` / `end-input` — Обработчик мгновенного ввода текста в поле или смещения ползунка.
- `on-hover(id)` / `end-hover` — Обработчик наведения курсора мыши на элемент.
- `on-key(клавиша)` / `end-key` — Обработчик нажатия заданной клавиши на клавиатуре.
- `every(мс)` / `end-every` — Запуск циклического интервального таймера каждые N миллисекунд.
- `wait(мс)` / `end-wait` — Отложенное выполнение блока команд через указанное число миллисекунд.
- `var(имя = значение)` — Объявление переменной или обновление ее текущего значения.
- `add-var(имя, число)` — Инкремент значения числовой переменной на заданное число.
- `chek(условие)` / `else` / `end-chek` — Блок ветвления и проверки логических условий.
- `val(id)` — Считывание текущего значения из поля ввода, ползунка или выпадающего списка.
- `is-checked(id)` — Проверка состояния флага checkbox (возвращает true или false).
- `set-text(id, текст)` — Обновление текста элемента (поддерживает интерполяцию `{переменная}`).
- `set-val(id, значение)` — Установка нового значения в поле ввода или слайдер.
- `clear-val(id)` — Очистка содержимого поля ввода.
- `repaint-color(id, цвет)` — Динамическое изменение цвета текста и подсветки элемента.
- `repaint-bg(id, цвет)` — Изменение фонового цвета элемента или всей страницы (body).
- `hide(id)` — Скрытие элемента со страницы.
- `show(id)` — Отображение скрытого элемента.
- `toggle(id)` — Переключение видимости элемента (скрыть / показать).
- `set-img(id, ссылка)` — Замена источника изображения в элементе картинки.
- `play-anim(id, тип, время)` — Запуск CSS-анимации на элементе (pulse, shake, spin, float, slide).
- `move(id, x, y)` — Анимационное или прямое перемещение элемента в координаты (x, y).
- `save(ключ, значение)` — Запись значения в локальное постоянное хранилище браузера (localStorage).
- `load(ключ)` — Извлечение сохраненного значения из localStorage по ключу.
- `alert(текст)` — Отображение всплывающего модального диалога браузера.
- `log(текст)` — Вывод отладочного сообщения в консоль разработчика браузера (F12).
- `sound(ссылка)` — Воспроизведение звукового аудиофайла (.mp3 или .wav).
- `go(ссылка)` — Навигационный переход на указанный URL-адрес или страницу.
- `reload()` — Принудительная перезагрузка текущей веб-страницы.
