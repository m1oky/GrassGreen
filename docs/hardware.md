# Библиотека `!hardware!` (Аппаратный опрос ПК)

Библиотека `!hardware!` (псевдонимы: `!hw!`, `!sysinfo!`, `!device!`) предоставляет мощный и высокоуровневый синтаксис для опроса всех аппаратных компонентов компьютера: процессора (CPU), оперативной памяти (RAM), дисков (SSD/NVMe/HDD), сети и интернета (Network), графического процессора (GPU), материнской платы, BIOS и шины PCI.

Библиотека полностью работает как в пользовательском режиме (Windows / Linux), так и в автономном режиме ядра операционной системы (**`--freestanding` / `--kernel` / `--multiboot`**).

---

## Подключение библиотеки

```grass
!GrassGreen!
!hardware!
```

---

## 1. Процессор (CPU / ЦПУ)

Аппаратный опрос параметров, топологии, кэша, частоты, нагрузки, виртуализации и температуры:

| Функция | Возвращает | Описание |
| :--- | :--- | :--- |
| `hw_cpu_vendor()` | `string` | Производитель процессора (`"GenuineIntel"`, `"AuthenticAMD"`, `"TCGTCGTCGTCG"`) |
| `hw_cpu_brand()` / `hw_cpu_name()` | `string` | Полное коммерческое название модели процессора |
| `hw_cpu_cores()` | `int` | Число физических ядер процессора |
| `hw_cpu_threads()` / `hw_cpu_logical()` | `int` | Число логических потоков (процессоров) |
| `hw_cpu_sockets()` | `int` | Число сокетов процессора |
| `hw_cpu_family()` | `int` | Семейство микроархитектуры |
| `hw_cpu_base_freq()` | `int` (МГц) | Базовая тактовая частота процессора |
| `hw_cpu_freq()` | `int` (МГц) | Текущая тактовая частота |
| `hw_cpu_usage()` | `int` (%) | Загрузка процессора в реальном времени (0 - 100%) |
| `hw_cpu_temp()` | `int` (°C) | Температура процессора |
| `hw_cpu_cache_l1()` | `int` (КБ) | Объем кэш-памяти 1-го уровня (L1 Cache) |
| `hw_cpu_cache_l2()` | `int` (КБ) | Объем кэш-памяти 2-го уровня (L2 Cache) |
| `hw_cpu_cache_l3()` | `int` (КБ) | Объем кэш-памяти 3-го уровня (L3 Cache) |
| `hw_cpu_virt()` | `string` | Статус аппаратной виртуализации (`"Включено"` / `"Enabled"`) |
| `hw_uptime_sec()` | `int` (сек) | Время непрерывной работы системы в секундах |
| `hw_uptime_str()` | `string` | Время работы в формате Диспетчера задач (`"ДД:ЧЧ:ММ:СС"`) |
| `hw_rdtsc()` | `int` | Аппаратный счетчик тактов Time-Stamp Counter |

## 2. Оперативная память (RAM / ОЗУ)

Мониторинг объема, использования, кэшированной памяти, скорости, форм-фактора и модели:

| Функция | Возвращает | Описание |
| :--- | :--- | :--- |
| `hw_ram_total()` | `int` (МБ) | Общий объем физической оперативной памяти |
| `hw_ram_used()` / `proc_mem` | `int` (МБ) | Объем занятой памяти в мегабайтах |
| `hw_ram_free()` | `int` (МБ) | Объем свободной / доступной памяти |
| `hw_ram_cached()` | `int` (МБ) | Объем кэшированной памяти (System Cache) |
| `hw_ram_speed()` | `int` (МГц) | Скорость модулей ОЗУ (например `3200` МГц / MT/s) |
| `hw_ram_temp()` | `int` (°C) | Температура модулей памяти |
| `hw_ram_model()` | `string` | Полная модель и производитель планок памяти (из SMBIOS DMI Type 17) |
| `hw_ram_form()` | `string` | Форм-фактор памяти (`"DIMM"` / `"SODIMM"`) |

---

## 3. Дисковые накопители (DISK / Диск)

Опрос накопителей (NVMe, SSD, HDD), файловой системы, скоростей и времени ответа:

| Функция | Возвращает | Описание |
| :--- | :--- | :--- |
| `hw_disk_model()` | `string` | Название и модель накопителя (например `"SAMSUNG MZVLQ512HALU"`) |
| `hw_disk_type()` | `string` | Тип диска (`"NVMe SSD"`, `"SATA SSD"`, `"HDD"`) |
| `hw_disk_size()` | `int` (ГБ) | Полная емкость диска |
| `hw_disk_free()` | `int` (ГБ) | Свободное место на диске |
| `hw_disk_format()` | `string` | Формат файловой системы (`"NTFS"`, `"FAT32"`, `"ext4"`) |
| `hw_disk_temp()` | `int` (°C) | Температура накопителя |
| `hw_disk_read_speed()` | `int` (МБ/с) | Скорость чтения данных |
| `hw_disk_write_speed()` | `int` (МБ/с) | Скорость записи данных |
| `hw_disk_resp_time()` | `int` (мс) | Среднее время ответа накопителя |
| `hw_disk_usage()` / `hw_disk_active()` | `int` (%) | Активное время диска (0 - 100%) |
| `hw_disk_is_system()` | `int` | `1`, если диск является системным загрузочным |
| `hw_pagefile_total()` | `int` (МБ) | Общий объем файла подкачки (Commit Limit) |
| `hw_pagefile_used()` | `int` (МБ) | Занятый объем файла подкачки (Commit Total) |

## 4. Сеть и Интернет (NETWORK / Сеть)

Мониторинг сетевых интерфейсов, скорости передачи и IP-адресов:

| Функция | Возвращает | Описание |
| :--- | :--- | :--- |
| `hw_net_adapter()` | `string` | Название активного сетевого адаптера |
| `hw_net_type()` | `string` | Тип подключения (`"Ethernet"`, `"Wi-Fi"`, `"VPN/Tunnel"`) |
| `hw_net_ipv4()` | `string` | Локальный IPv4-адрес |
| `hw_net_ipv6()` | `string` | IPv6-адрес адаптера |
| `hw_net_recv_speed()` | `int` (Кбит/с) | Скорость получения данных (Download) |
| `hw_net_send_speed()` | `int` (Кбит/с) | Скорость отправки данных (Upload) |
| `hw_net_recv_total()` | `int` (МБ) | Всего получено данных по сети |
| `hw_net_send_total()` | `int` (МБ) | Всего отправлено данных по сети |

---

## 5. Графический процессор (GPU / Видеокарта)

Опрос видеокарт через Direct3D / DXGI и шину PCI:

| Функция | Возвращает | Описание |
| :--- | :--- | :--- |
| `hw_gpu_name()` | `string` | Название видеокарты (`"Radeon RX 580 Series"`, `"Intel UHD Graphics"`) |
| `hw_gpu_usage()` | `int` (%) | Загрузка графического ядра (0 - 100%) |
| `hw_gpu_temp()` | `int` (°C) | Температура видеочипа |
| `hw_gpu_vram_total()` | `int` (МБ) | Выделенная видеопамять (Dedicated VRAM) |
| `hw_gpu_vram_used()` | `int` (МБ) | Занятая видеопамять |
| `hw_gpu_vram_shared()` | `int` (МБ) | Общая системная видеопамять (Shared Memory) |

---

## 6. Материнская плата, BIOS и шина PCI

| Функция | Возвращает | Описание |
| :--- | :--- | :--- |
| `hw_board_vendor()` | `string` | Производитель системной платы |
| `hw_board_model()` | `string` | Модель материнской платы |
| `hw_bios_vendor()` | `string` | Разработчик прошивки BIOS / UEFI |
| `hw_bios_date()` | `string` | Дата релиза прошивки BIOS |
| `hw_bios_version()` | `string` | Версия BIOS |
| `hw_pci_count()` | `int` | Количество обнаруженных физических устройств на шине PCI |
| `hw_reboot()` | `void` | Аппаратная перезагрузка компьютера |

## Пример использования в коде

```grass
!GrassGreen!
!hardware!

int main() {
    gout << "=== ДИСПЕТЧЕР ЗАДАЧ ===" << endl;
    gout << "ЦПУ:     " << hw_cpu_brand() << " (" << hw_cpu_cores() << " ядер, " << hw_cpu_threads() << " потоков)" << endl;
    gout << "Частота: " << hw_cpu_freq() << " МГц | Нагрузка: " << hw_cpu_usage() << "% | Нагрев: " << hw_cpu_temp() << "°C" << endl;
    gout << "ОЗУ:     " << hw_ram_used() << " / " << hw_ram_total() << " МБ (" << hw_ram_speed() << " МГц " << hw_ram_form() << ")" << endl;
    gout << "Диск:    " << hw_disk_model() << " [" << hw_disk_type() << "] " << hw_disk_size() << " ГБ" << endl;
    gout << "Сеть:    " << hw_net_adapter() << " (" << hw_net_ipv4() << ")" << endl;
    gout << "ГПУ:     " << hw_gpu_name() << " | VRAM: " << hw_gpu_vram_total() << " МБ | " << hw_gpu_temp() << "°C" << endl;
    return 0;
}
```
