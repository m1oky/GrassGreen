# Библиотека !asm! — Встроенный ассемблер ядра

Библиотека `!asm!` предоставляет низкоуровневый доступ к архитектуре процессора x86_64, аппаратным прерываниям, портам ввода-вывода, системным управляющим регистрам (CR0-CR4) и ассемблерным вставкам без использования внешних зависимостей (таких как NASM или GAS).

---

## Подключение

```grass
!GrassGreen!
!asm!

int main() {
    // Код на ассемблере и прямые вызовы ядра
    return 0;
}
```

---

## 1. Аппаратные прерывания и управление процессором

| Функция | Описание |
|---|---|
| `cli()` | Сброс флага прерываний (инструкция `CLI`). Запрещает аппаратные прерывания. |
| `sti()` | Установка флага прерываний (инструкция `STI`). Разрешает аппаратные прерывания. |
| `hlt()` | Остановка процессора до прихода следующего прерывания (инструкция `HLT`). |
| `pause()` | Оптимизационная пауза для спинлоков (инструкция `PAUSE`). |
| `nop()` | Холостая операция процессора (инструкция `NOP`). |
| `invlpg(addr)` | Сброс записи TLB для виртуального адреса `addr` (инструкция `INVLPG`). |
| `rdtsc()` | Чтение 64-битного счетчика тактов процессора Time-Stamp Counter (`RDTSC`). |

---

## 2. Порты ввода/вывода (I/O Ports)

Прямое общение с контроллерами материнской платы (клавиатура PS/2, PIT-таймер, COM-порты):

| Функция | Описание |
|---|---|
| `in(port)` / `in8(port)` | Чтение 8-битного байта из порта ввода-вывода x86 (инструкция `IN AL, DX`). |
| `in16(port)` | Чтение 16-битного слова из порта ввода-вывода x86 (инструкция `IN AX, DX`). |
| `in32(port)` | Чтение 32-битного двойного слова из порта (инструкция `IN EAX, DX`). |
| `out(port, val)` / `out8(port, val)` | Запись 8-битного байта в порт ввода-вывода x86 (инструкция `OUT DX, AL`). |
| `out16(port, val)` | Запись 16-битного слова в порт ввода-вывода x86 (инструкция `OUT DX, AX`). |
| `out32(port, val)` | Запись 32-битного двойного слова в порт (инструкция `OUT DX, EAX`). |

---

## 3. Системные регистры процессора

| Функция | Описание |
|---|---|
| `read_cr0()` | Чтение регистра управления CR0 (флаги PG, WP, PE защищенного режима). |
| `write_cr0(val)` | Запись нового значения в регистр CR0. |
| `read_cr2()` | Чтение регистра CR2 (линейный адрес Page Fault). |
| `read_cr3()` | Чтение базового физического адреса корневой таблицы страниц PML4 / Page Directory. |
| `write_cr3(val)` | Установка нового адреса каталога страниц (переключение адресного пространства). |
| `read_cr4()` | Чтение регистра CR4 (флаги PAE, PSE, OSFXSR). |
| `write_cr4(val)` | Запись в регистр CR4. |
| `read_rflags()` | Чтение регистра флагов RFLAGS. |
| `write_rflags(val)` | Запись флагов процессора. |
| `cpuid_eax(leaf)` | Вызов инструкции CPUID с получением регистра EAX. |
| `cpuid_ebx(leaf)` | Вызов инструкции CPUID с получением регистра EBX. |
| `cpuid_ecx(leaf)` | Вызов инструкции CPUID с получением регистра ECX. |
| `cpuid_edx(leaf)` | Вызов инструкции CPUID с получением регистра EDX. |

---

## 4. Встроенные ассемблерные вставки (Inline Assembly)

Поддерживается как блочный синтаксис `asm { ... }`, так и строковый `asm("...")`:

```grass
!GrassGreen!
!asm!

int main() {
    // Блочная ассемблерная вставка
    asm {
        cli
        xor eax, eax
        mov eax, cr0
        or eax, 1
        mov cr0, eax
        sti
    }

    // Однострочная ассемблерная инструкция
    asm("nop; pause; rdtsc;");

    // Выполнение сырых машинных байт шеллкода
    asm_bytes("90 90 C3");

    // Получить дамп сгенерированного машинного кода
    take hex = asm_machine_hex();
    gout << "Machine code: " << hex << endl;
    return 0;
}
```

---

## Преимущества встроенного ассемблера

- **Zero Dependencies:** Не требует установки сторонних утилит (NASM, Yasm, GAS, LLVM MC).
- **Двойной режим:**
  - В режиме `--freestanding` исполняется напрямую на процессоре голого железа или в эмуляторе QEMU.
  - В режиме обычной ОС симулирует и эмулирует регистры процессора без вызова аппаратного падения Windows/Linux (Ring 3 Protection Fault).
