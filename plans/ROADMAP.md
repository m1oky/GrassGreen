# 🚀 GrassGreen v4.0 — The Evolution (Архитектурный роадмап)

> Статус: Проектирование / Исследование  
> Цель: Переход от экспериментальной Stack VM к полноценному системному языку с нативными структурами данных и тулчейном.

---

## 1. Фундаментальные структуры данных
- [ ] **Динамические массивы (`array`)**
  - Синтаксис: `take list = []; list.push(item);`
  - Индексация по `list[i]`, сортировка, получение длины через `len(list)`.
  - Динамическое перевыделение памяти в куче без утечек.
- [ ] **Пользовательские структуры (`struct`)**
  - Объявление составных типов: `struct Player { string name; int hp; take x; }`
  - Доступ к полям через точку (`player.hp = 100`).

---

## 2. Архитектура ядра и исполнения (VM / JIT)
- [ ] **Регистровая виртуальная машина (Register-based VM)**
  - Переход от стека к виртуальным регистрам (`R0`..`R15`).
  - Сокращение количества опкодов в цикле на 40–60%.
- [ ] **Экспериментальный Mini-JIT (x86-64)**
  - Выделение исполняемых страниц через `VirtualAlloc(PAGE_EXECUTE_READWRITE)`.
  - Компиляция горячих циклов напрямую в машинные опкоды процессора.

---

## 3. Модульность и сборка
- [ ] **Настоящий импорт файлов (`import`)**
  - Возможность писать библиотеки на самом `.grass`: `import "math_utils.grass";`
  - Склейка синтаксических деревьев на этапе лексера.
- [ ] **Многопоточность (`thread` / `async`)**
  - Вынос тяжелых задач (сервер `GrassNet`, расчеты) в отдельные потоки Win32.
  - Оконный интерфейс `!interface!` больше не зависает при сетевых вызовах.

---

## 4. Инструментарий и экосистема Windows
- [ ] **Нативный `setup.exe` на C++**
  - Автоматическая прописка пути компилятора в системный `PATH` через реестр Windows.
  - Привязка расширения `.grass` и иконок `logo.svg` в проводнике ОС.
- [ ] **Официальное расширение для VS Code**
  - Автоматическая установка в `.vscode/extensions/grassgreen-tools/`.
  - Пакет сниппетов (автодополнение функций всех 12 библиотек).
  - Всплывающие подсказки параметров (LSP-протокол).
